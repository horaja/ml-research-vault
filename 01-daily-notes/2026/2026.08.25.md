**Core**

- **E2S-Pruner** — `arXiv:2608.23253` — Training-free visual token pruning via multi-layer evidence fusion (visual + semantic + spatial signals). Achieves 40–67% token reduction with minimal accuracy drop across LLaVA-1.5/InternLM2. Baseline SURF must beat. Evidence score aggregation is close to SURF's structural prior concept but lacks language conditioning and action alignment. *Read abstract; no action this week unless spec is written first.*

- **TOWN-VLA** — `arXiv:2608.23224` — Documents prompt-form collapse: instruction fine-tuning collapses visual token utilization from 92.47% (base) to 3.00% (IT model). Proposes "typed slow-path" (separate query heads for spatial vs. semantic vs. action tokens) to restore multi-modal grounding. **Critical architectural constraint**: SURF injection mechanism must account for this collapse — inserting a selection gate after IT-collapsed attention may amplify rather than fix the problem. *Must read in full before contrastive alignment spec.*

- **Pointing-VLA** — `arXiv:2608.23138` — Typed geometry heads producing OFG (Object-Focused Geometry) heatmaps for spatial grounding. Achieves strong spatial accuracy without removing tokens; beats token-pruned baselines on manipulation tasks. Differentiation challenge: if spatial grounding alone recovers performance, token selection may be unnecessary. *Need to understand when token removal adds value beyond grounding.*

**Adjacent**

- **Act with Intent** — `arXiv:2608.23478` — Intent distillation: extract compact intent representations from policy rollouts, use as contrastive signal for visual encoder. Alternative to SURF's explicit token selection — distilled intent vectors might implicitly select relevant patches. Relevant to [[02-projects/surf/claims/language helps]]. *Skim.*

- **GeoWAM** — `arXiv:2608.23486` — Geometry-first world action model for autonomous driving (3D structure → occupancy → action). Same structural-prior argument as SURF but in 3D for driving: structure reduces hallucination and improves OOD generalization. Supporting evidence for [[02-projects/surf/claims/structure helps]]. *File as evidence; no deep read needed.*

- **Grounding Isn't Knowing** — `arXiv:2608.23074` — VLMs achieve spatial reasoning without patch-level token localization; models exploit holistic attention patterns. Challenges necessity of token-level selection for spatial tasks. Directly relevant to SURF's core assumption. *Must understand: if VLMs already route around missing tokens, what is SURF actually adding?*

**Horizon**

- **How to Train a Critic Stably** — `arXiv:2608.23566` — BPCO (Bounded Policy Conservative Optimization) for stable offline RL critic training. Reduces Q-value overestimation without explicit conservatism penalty. Applicable to SURF's budget policy RL training (efficiency/RL module). *File; read when RL module moves to active development.*

- **Sigmoid Attention for KV Cache Eviction** — `arXiv:2608.23296` — Sigmoid attention reduces soft-to-hard mismatch when learned eviction scores are binarized at inference. Relevant to SURF's scorer-gate design: if the gate uses soft scores during training but hard eviction at inference, this mismatch is the same problem. *Skim gating section.*

## questions

New today:
- Does SURF need to beat E2S-Pruner on efficiency, on generalization, or on both? The spec should be explicit about the positioning.
- TOWN-VLA collapse (92.47%→3.00%): does SURF's selection gate need to operate *before* instruction-tuning collapses attention, or can it be inserted post-hoc into a collapsed model?
- Pointing-VLA achieves spatial grounding without token removal. Under what conditions does token removal add value beyond what spatial grounding alone provides?
- "Grounding Isn't Knowing": if VLMs bypass patch-level localization already, is SURF optimizing a bottleneck that doesn't exist in well-trained models?
- Sigmoid attention mismatch: does the SURF scorer gate suffer the same soft-to-hard discrepancy at inference? Should the gate be trained with hard Gumbel-softmax from the start?

Carried forward (see [[02-projects/surf/questions]]):
- Is patch-level selection the right granularity, or should SURF select at the object/region level?
- What is the right evaluation protocol for action-relevant token selection (not just VQA accuracy)?
- How does SURF interact with KV-cache compression at inference — are they composable?
