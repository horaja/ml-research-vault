## opener

Wednesday, July 29. Contrastive alignment spec unwritten — 23 weeks. GSPA unread — day 46. "When Attention Collapses" (STS) unread — day 35. Visual Access Boundaries unread — day 15.

**DC-WAM** (Ji et al.) asks what the visual modality should actually learn for robot control and answers: dynamic change, not geometric structure. The paper proposes dynamic-centric visual supervision — teaching the vision encoder to represent which patches undergo meaningful state transitions during action execution — in contrast to surf's line-density prior, which represents geometric structure. This is the most direct collision with [[claims/structure helps]] surfaced this cycle: dynamic-centric and structure-centric supervision are competing answers to the same question, not complementary ones. The diagnostic is the same co-location test as for ViTacWorld (7/27) and DeVA (7/28): on LIBERO contact-event frames, do DC-WAM's dynamic patches and surf's line-density patches agree? Agreement = structure co-locates with dynamic change; disagreement = they're targeting different properties of the scene, and the ablation table must include both baselines.

**Zhao et al.** (eye-hand coordination) frames gaze allocation as an information-demand optimization: fixation goes to regions where the gap between task-required certainty and current visual evidence is largest. This is the cognitive science framing surf's visual allocation implicitly assumes but has never made precise. If line density is a proxy for information demand at manipulation-relevant regions, the two maps should agree on LIBERO grasping frames. If they don't, the prior module is not approximating information demand — it's approximating geometric salience, which is a weaker claim.

Write the spec.

  Computational model in which gaze is allocated to minimize information deficit (task-required certainty minus current evidence) for motor control.
