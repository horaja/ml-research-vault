**core**

- [FastVLA: Task-Conditioned and Temporally Adaptive Visual Token Compression for Efficient VLA Models](https://arxiv.org/abs/2610.22146) — Xu, Qian, Tu, Sui · arXiv (Oct 2026)
  Training-free, instruction-attention-scored token compression that adapts the per-step token budget to scene dynamics. Direct structural competitor: same motivation (task relevance ≠ generic saliency) but post-encoder attention vs SURF's pre-encoder V4 prior. New SURF question: is a temporally static selection budget suboptimal when task-critical regions shift mid-task?

- [SVD-Prune: Spectral Vision Token Pruning under Extreme Compression](https://arxiv.org/abs/2611.02284) — Apedo, Poreba, Szczepanski, Bouchafa · arXiv (Nov 2026)
  Formulates pruning as preserving dominant low-rank spectral structure via SVD leverage scores; training-free, architecture-agnostic, applicable pre-encoder, post-encoder, or hybrid. Must-add baseline for the positioning note: do SVD leverage scores correlate with what a V4 shape prior selects? If yes, SVD-Prune is a simpler baseline SURF needs to beat; if not, the orthogonality is a selling point.

- [GuidedAttention: Interpretable and Correctable Visual Attention for OOD-Robust Robot Manipulation via Imitation Learning](https://arxiv.org/abs/2607.21049) — Murooka, Nakajo, Shirai, Motoda · arXiv (Jul 2026)
  Predicts task-relevant attention keypoints as an explicit intermediate representation conditioning a diffusion policy; user-correctable at rollout init, auto-propagated by tracking; consistently improves under positional and appearance OOD shifts. Closest published competitor in architecture pattern: explicit spatial selection → condition policy. SURF difference: GuidedAttention learns keypoints from demonstrations; SURF's V4 prior requires no training distribution.

**adjacent**

- [CoBoVLA: Decoupling Language from Action with Discrete Codes for Robust and Interpretable Robot Manipulation](https://arxiv.org/abs/2611.22395) — arXiv (Nov 2026)
  Finds 22–52 point performance drop under paraphrasing in existing VLAs (0.6B–7.5B); attributes it to language-action entanglement in joint training. Adjacent to [[02-projects/surf/claims/language helps]]: if language routing is entangled with action generation in current VLAs, SURF's language-conditioned selection must account for whether the backbone's language representations generalize or overfit to instruction phrasing.

- [Don't Ask the LLM: Visual Token Pruning with Spectral Structure and Semantic Relevance](https://arxiv.org/abs/2610.38303) — Shin, Lim, Park, Choi · arXiv (Oct 2026)
  Finds [CLS] attention scattered and background-biased under aggressive compression; proposes a spectral structure + semantic relevance signal computed without LLM queries. The [CLS] weakness finding is supporting evidence for SURF's claim that generic attention is inadequate for principled selection — a structural prior (V4 shape or spectral) is needed. Competes with SURF in the "no task-distribution signal" space.

**horizon**

- [Explicitly Modeling Subcortical Vision with a Neuro-Inspired Front-End Improves CNN Robustness](https://arxiv.org/abs/2506.03089) — Piper, Oliveira, Marques · NeurIPS 2025
  EVNets: coupling a CNN with a subcortical + V1-mimicking front-end (EVBlock) improves OOD robustness across visual perturbations. Directly supports [[02-projects/surf/claims/v4 relevance]]: if V1 structure at the front end improves OOD robustness, the V4 structure SURF uses should do so at the next level of the hierarchy. The subcortical→V1→V4 chain makes the biological motivation more principled than V4 alone.
