# 2026-10-11

## opener

Positioning note is day 47. No new structural blockers.

Three papers today converge on a new competitive framing: the "where to look" problem is now being solved by three data-driven mechanisms — stage-specific token importance (When and What to Prune, extending VLA-ACL), robot-state grounding (ThinkProprio), and end-to-end action learning (Attention from Action). SURF's structural prior is the only training-free, zero-shot approach in this set. The positioning note must address this explicitly: the question is no longer "does structure help?" but "when is a geometric prior better than a data-driven alternative, and under what data/compute constraints?"

ThinkProprio is the most actionable new entry: it discretizes proprioception into VLM tokens and uses them to gate visual patches before computation. If robot state grounds visual selection, SURF's structural prior is only needed when proprioception is uninformative or insufficient — e.g., on novel objects, partial observability, or early in a manipulation where the grasp pose is undetermined. This is a concrete design boundary that the contrastive alignment spec should incorporate.

Cao et al. is day 12. Still unread. Still a required baseline for [[02-projects/surf/claims/language helps]].

**core**

- [When and What to Prune? Stage-Aware Visual Token Pruning for Efficient VLA](https://www.semanticscholar.org/paper/11187459e83137556bc7d856ec19e256d7872a06) — Shi et al. · preprint
  Extends the action-consistency framing (VLA-ACL, COSTGRAD) to stage-specific pruning: different inference stages require different token sets, and existing attention-score / diversity-based methods miss this. SURF's structural prior operates at the input stage (vision encoding) — this paper forces the question of whether input-stage selection is the right intervention point, or whether task relevance only becomes interpretable at later VLM layers.

- [Think Proprioceptively: State-Grounded Visual Token Selection for VLA Policies](https://www.semanticscholar.org/paper/2ce0a7201ebc0b4804a7f28d3536338e57e5c345) — Wang et al. · preprint
  ThinkProprio discretizes proprioception into VLM-vocabulary tokens and uses them jointly with the instruction to gate visual patches before VLM computation. New axis alongside structural priors and language conditioning: robot state as a visual selection signal. Check: does proprioceptive gating overlap with line-drawing selection on manipulation scenes, or do they select structurally distinct token subsets? If they overlap, ThinkProprio is an empirical oracle for SURF's structural prior — structured patches are the ones robot state already identifies as task-relevant.

- [Attention from Action, for Action: Emergent Visual Bottlenecks for Policy Learning](https://www.semanticscholar.org/paper/97c2db623247367a7622c4c8b0c79bb41f098dcc) — Zhuang et al. · preprint
  Label-free visual ROI emerges from action supervision: ROI boundaries are inferred from gripper/motion events rather than external labels (gaze, classes, affordances). Direct competitor to SURF's structural prior — if ROI boundaries emerge from action feedback end-to-end, a geometric prior is redundant when sufficient training data exists. SURF's argument: geometric priors generalize to new tasks and objects without requiring action-labeled data. Required check: does the emergent ROI correspond to the regions SURF's line-drawing prior selects?

**adjacent**

- [History-Conditioned Spatio-Temporal Visual Token Pruning for Efficient Vision-Language Navigation](https://www.semanticscholar.org/paper/4755e2c70d9686aeb663bcb341c339a8edc6df33) — Wang et al. · arXiv
  Training-free history-conditioned spatio-temporal token pruning for VLN (navigation context, not manipulation). Published architecture closest to [[02-projects/surf/claims/iterative selection]] in the navigation regime: history conditioning provides the iterative-access signal that SURF's uncertainty-based refinement would provide in manipulation. Check: does temporal history substitute for iterative geometric re-sampling in navigation, and does the analogy hold in closed-loop VLA manipulation where scene state evolves differently?

- [REACT: Rolling Denoising and Dual Decoupling for Reactive Robot Control with VLA Models](https://arxiv.org/abs/2610.12007v1) — Xiong et al. · arXiv
  Rolling denoising resolves the long-chunk vs. reactivity tradeoff in flow-based VLAs: each denoising step is a potential visual reassessment point. If SURF's iterative selection module inserts token re-selection at denoising steps, REACT's architecture provides natural iteration points without full re-encoding. Relevant to the iterative selection module spec: does selective visual re-sampling at each denoising step provide the same benefit as SURF's coarse-to-fine allocation?

- [Depth Matters: Language-Guided Spatial Representation Learning for Robot Manipulation](https://www.semanticscholar.org/paper/d6087ec299513c92af00e2061701d128aa135681) — Zhu et al. · CAA
  Depth + language conditioning for a decoupled, reusable visual encoder in VLA. Implements structure (depth) + language conditioning for spatial representation — same combination as SURF but using depth rather than line drawings. Direct baseline for [[02-projects/surf/claims/structure helps]]: depth-guided spatial representation vs. line-drawing-guided. Check: does language-guided depth representation outperform line-drawing selection in manipulation datasets where depth is available, and what happens when depth is unavailable (novel environments)?

## questions

New from today:
- When and What to Prune: Is input-stage (vision encoding) the correct intervention point for structural priors, or does task relevance only become interpretable at later VLM layers where language conditioning has taken effect? If the latter, SURF's prior belongs between the vision encoder and the first cross-attention layer, not before the encoder.
- ThinkProprio: Does proprioceptive gating select the same visual patches as SURF's structural prior on shared manipulation scenes? If they align, ThinkProprio's action-supervision signal is an empirical oracle for the structural prior — and the geometric prior's value is that it approximates this oracle without proprioceptive supervision. If they diverge, they select for different things.
- ThinkProprio: Does conditioning on robot state at input time improve spatial coverage of contact regions more than SURF's line-drawing prior, especially during approach phases when grasp pose is still uncertain?
- Attention from Action: Does the emergent ROI (from gripper/motion events) overlap with SURF's structural selection on shared manipulation scene images? If yes, SURF's geometric prior approximates action-derived ROI at zero training cost.
- REACT: Can SURF's iterative visual re-selection be inserted at each denoising step in REACT's rolling framework without breaking the dual-decoupling mechanism? What is the compute overhead of per-step structural re-selection?

Carried from 2026-10-10:
- VLA-ACL: Do SURF's geometrically-selected patches overlap with VLA-ACL's action-consistent tokens on manipulation scenes?
- When Text Matters: What specific failure modes does it identify for contrastive token scoring — failure in the text-visual similarity metric itself, in the selection criterion, or in the downstream task objective?
- Compact Robot Policies: Do the fine-grained visual features driving manipulation performance correspond to boundary/edge patches consistent with the line-drawing prior?

## risks

- **Positioning note (day 47)**: Three new data-driven "where to look" methods (stage-aware, proprioception-gated, action-emergent) sharpen the competitive landscape. The positioning note must now argue explicitly: when does a geometric zero-shot prior beat data-driven alternatives? Write today.
- **ThinkProprio as a cheap data-driven oracle**: If robot-state gating selects the same patches as SURF's structural prior, ThinkProprio is a stronger baseline (uses task-relevant state + instruction vs. geometry alone). SURF must either (a) show patch overlap (geometric ≈ state-grounded) to establish it as a training-free proxy, or (b) show divergence (geometric captures what state doesn't) to establish complementarity.
- **Attention from Action: action-emergent ROI**: If ROI boundaries emerge from action supervision without labels, structural priors have no advantage on datasets with sufficient action demonstrations. SURF's value proposition shifts to low-data, zero-shot, or novel-object generalization.
