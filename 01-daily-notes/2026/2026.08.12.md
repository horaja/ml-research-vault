Two papers today add training-design constraints that bear on the spec. **WCM** (Fei et al., 2026-07-31) shows that single-frame value estimators fail under partial observability in VLA RL, requiring a multi-frame world critic — temporal consistency constraint for surf's scorer that must be addressed in the contrastive alignment training section. **Explicit Language Memory** (Xu et al., 2026-08-05) shows that a single global instruction is insufficient for compositional long-horizon VLA generalization; surf's scorer takes language as a gating signal, so the spec's language section must account for whether the instruction input should be global or sub-task-decomposed.

**See2Think** (Yan et al., 2026-07-29) is a benchmark-scale confirmation of the "Illusion of Visual Tool-Use" (8/9): intermediate visual states are systematically not causally used by multimodal models. This strengthens the empirical case for pre-inference structural selection over in-context visual tools — directly relevant to surf's framing.

## questions

- Explicit Language Memory × [[claims/language helps]] granularity: Surf's scorer gates visual patches using the global task instruction. Xu et al. show global instruction is insufficient for compositional generalization; sub-task memory substantially outperforms. Should surf's language conditioning input be redesigned to accept a sub-task query (from a decomposition module) rather than a global instruction? What is the minimal language signal granularity that still allows training-free or lightweight scorer design?
- See2Think × pre-inference selection framing: See2Think + Illusion of Visual Tool-Use (8/9) together establish that in-context visual operations are not causally used. Does this mean surf's pre-inference selection is the only reliable locus for visual computation reduction, or could there be an in-context approach that avoids the in-context tool-use failure (e.g., in-context selection that doesn't generate new visual states but selects from existing token activations)?
- WCM × scorer temporal consistency: WCM's multi-frame critic requires the model to maintain consistent representations across frames. Surf's contrastive scorer selects patches independently per frame. Should the contrastive training objective include a temporal consistency term — e.g., selected-token-set Jaccard similarity across adjacent frames with same task state? Or is temporal consistency enforced implicitly if the structural prior (line density) is stable across adjacent frames of the same scene?
- Semantic Anchoring × TEMPO convergence: Both Semantic Anchoring (Xu et al.) and TEMPO (day 3) identify pretrained VLM representation preservation as a key training constraint. Semantic Anchoring uses shared observation-execution space regularization; TEMPO uses frozen backbone. Are these complementary (both are necessary), competing (choose one), or redundant (one subsumes the other) for surf's scorer pre-training design? Does the mirror neuron theory motivation add a biological grounding that connects to [[claims/v4 relevance]]?
- FM-VLA × [[claims/iterative selection]] trigger design: Three trigger designs now in view: kinematic state change (KEMO), quality metric (Adaptive-WAM), contact force signal (FM-VLA). Surf's iterative selection mechanism needs a trigger that generalizes without tactile hardware. Is uncertainty-gated selection (AtVLA-style) the fallback trigger, or can kinematic state change be approximated from visual observations alone (removing hardware dependency)?
