# 2026-10-17

## opener

Positioning note is day 53. No new structural blockers; the proprioceptive signal thread sharpens a latent question.

Three threads converge today. First, **ThinkProprio** closes the open question from 10/15: does proprioceptive gating select the same visual patches as SURF's structural prior? The answer now has a foil: ThinkProprio discretizes proprioception into VLM-vocabulary tokens and uses them to direct visual attention, which is a competing structural signal. If robot state already identifies which patches matter for the current action, SURF's geometric line-drawing prior must show what it adds beyond proprioception — most likely novel-object geometry and anti-shortcut coverage that joint-angle statistics cannot encode. This is a new positioning argument the note must absorb.

Second, **VLA-ACL** surfaces properly: action-consistency as the pruning criterion (keep tokens whose removal changes the action distribution) is the direct empirical test of whether geometric selection and action-relevance overlap on manipulation scenes. The 10/15 question is now answerable.

Third, **Token-World** reframes the iterative selection problem: instead of predicting future RGB and re-encoding, it predicts future token states directly. If future token importance is predictable in token space, [[02-projects/surf/claims/iterative selection]] can be closed-loop without RGB reconstruction.

Cao et al. is day 18. Read today.
