## papers

### core

**Matched Outcomes, Divergent Gaze: How Foveated MLLMs Search Compared to Humans** (auto)
Kerkouri et al. · arXiv:2608.16514 · 2026-08-17
[https://arxiv.org/abs/2608.16514](https://arxiv.org/abs/2608.16514)
Tests whether foveated MLLMs produce human-like scanpaths on goal-directed visual search (COCO). If matched-outcome tasks still diverge in gaze, gaze alignment is not a valid proxy for task competence. Resolves the open question in [[02-projects/surf/questions]] under evaluation: "Does [[eval/gaze]] measure task relevance, or similarity to human gaze?" — directly gates whether gaze metrics belong in surf's evaluation protocol at all.

**Learning task-adaptive visual-language relevancy for language-conditioned manipulation** (auto)
Luo et al. · S2 · 2026-07-14
[https://www.semanticscholar.org/paper/78fa37093cd4c0f6cd64b78006220edbf8f05919](https://www.semanticscholar.org/paper/78fa37093cd4c0f6cd64b78006220edbf8f05919)
TARL: learnable relevancy refinement module adapting frozen VLM visual-language attention to task-relevant patches using RGB-D observations. Closest existing implementation of surf's contrastive scorer concept for [[claims/language helps]]: frozen backbone + learned adapter for task-conditioned region selection. Missed for 5 weeks. Read before writing architecture section of contrastive alignment spec.

### adjacent

**τ₀-VLA: a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation** (auto)
arXiv:2608.16885 · 2026-08-17
[https://arxiv.org/abs/2608.16885](https://arxiv.org/abs/2608.16885)
Hierarchical VLA allocating additional test-time compute to difficult/consequential decisions guided by world-model predictions. Design reference for [[claims/iterative selection]]: world-model trigger for adaptive compute is a concrete implementation of surf's "refine when uncertain" loop. Contrast with ContactGuard (action-plan-failure trigger) and KEMO (event-driven trigger) — τ₀-VLA adds world-model cost as a third trigger mechanism.

**Hybrid-Level Instruction Injection for Video Token Compression in Multi-modal Large Language Models** (auto)
Liu et al. · arXiv:2503.16036 · 2025-03-20 · 23 citations
[https://arxiv.org/abs/2503.16036](https://arxiv.org/abs/2503.16036)
Instruction-conditioned video token compression with both token-level and frame-level conditioning; shows different instruction granularities capture complementary relevance signals. 23 citations — substantial. Formalizes the instruction granularity question for [[claims/language helps]] spec design: should surf's scorer condition on full instruction at patch level, sub-task level, or both?

### horizon

arXiv:2503.23062 · 2025-03-29 · 5 citations
