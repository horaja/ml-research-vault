**core**

- [Just Noticeable Difference Modeling for Token Compression in Vision-Language-Action Models](https://arxiv.org/abs/2608.21247v1) — Zhuoyuan Li et al. · arXiv · 2026-08-21
  Applies psychophysics-derived JND thresholds to drop visual tokens in VLA embodied agents — tokens whose patch content wouldn't be perceptibly different for downstream task execution. Directly competes with surf's token selection approach: JND operationalizes "information sufficiency" from the perceiver's side, surf's line-density prior approximates it from structural geometry. These are two different criteria for the same selection decision; the spec must position against JND before claiming geometric priors add unique value.

- [When does fusing hand-crafted knowledge with learned representations pay? A cost-normalized benchmark of stacking, substitution, and interference](https://arxiv.org/abs/2608.21098v1) — Ahmad AlMughrabi et al. · arXiv · 2026-08-21
  Controlled study benchmarking pinned Gabor targets (oriented edge/line-like structural filters, ~2% overhead) fused with learned visual representations — measuring when structural priors help, are redundant, or hurt. The Gabor baseline is a close proxy for surf's line-density prior; the "ablation gap" framing quantifies exactly when structure contributes over what the learned scorer already captures. Provides an empirical framework for the [[claims/structure helps]] go/no-go question surf currently lacks a controlled test for.

**adjacent**

- [The Cost of a Physics Prior Is Bounded by the Ablation Gap](https://arxiv.org/abs/2608.21059v1) — Boris Kriuk et al. · arXiv · 2026-08-21
  Theoretical result: the accuracy cost of enforcing any shape/physics constraint equals the gap between unconstrained and constrained validation performance — no more, no less. For surf, this means the worst-case cost of using the structural line-density prior instead of an unconstrained scorer is directly measurable as the ablation gap in [[experiments/contrastive alignment]]. If the gap is small, the prior is essentially free; if large, the prior is making non-trivial decisions that should be justified.

- [From Attention Masks to Inert Zero-Vector Tokens: OAttention and O-Closure for Token Dynamics](https://arxiv.org/abs/2608.21174v1) — Heyang Gong et al. · arXiv · 2026-08-21
  Assigns each token a continuous active-presence coefficient p_i = ||h_i||; "O-closure" makes zero-norm tokens inert to attention without explicit mask modification. Bridges hard token masking and full attention via a differentiable scalar. Relevant to surf's top-k binary selection: OAttention's norm-based presence score could replace Gumbel-Softmax for differentiable token selection in the contrastive scorer, and it raises the question of whether token norm already tracks structural/task relevance without any explicit prior.

- [PhysCaP: Grounding Code-as-Policy Agent with Physics-Informed Exploration](https://arxiv.org/abs/2608.21031v1) — Chen-Yu Lin et al. · arXiv · 2026-08-21
  Augments passive VLA policies with physics-informed active perception: the agent plans which regions to physically probe (tap, push) to infer latent properties (mass, friction) before grasping. Parallel to surf at the sequence level: where surf selects which 2D patches to compute over in a single observation, PhysCaP selects which 3D regions to physically probe across actions. The physics-informed exploration strategy is a richer version of surf's [[claims/iterative selection]] extended to multi-step active sensing.

**horizon**

- [Basin-Preserving Discretizations of Modern Hopfield Retrieval Dynamics: Energy Cells, Dissipation, and the Attention Limit](https://arxiv.org/abs/2608.21304v1) — Francisco R. Villatoro et al. · arXiv · 2026-08-21
  Proves the attention update is the exact difference-of-convex minimization step of a log-sum-exp Hopfield energy, and characterizes which discretizations preserve basins of attraction. Horizon framing: surf uses attention scores as token importance proxies — this result grounds why that works. A token in a deep attractor basin is "committed" to a stored pattern (task-relevant content); one near a basin boundary is ambiguous. Basin structure could formalize surf's claim that geometric tokens are more stable attractors than texture tokens under manipulation instructions.

## questions

- JND token compression × surf differentiation: JND drops tokens whose content change is below a perceptual threshold. Surf's structural prior selects tokens by geometric density. Do these criteria agree or disagree on manipulation frames? If a line-dense patch is also above the JND threshold (high content change = informative), there's no disagreement — surf's prior is a cheap proxy for JND. If they disagree (structure without content change, or content change without structure), that's the true differentiation argument. Testable on LIBERO frames.
- OAttention × surf scorer design: if token norms (||h_i||) already correlate with task-relevant content after a pre-trained VLA backbone, does surf's contrastive scorer add signal over OAttention's zero-cost norm-based presence score? If norms already select the right tokens, surf's architecture may only need a norm threshold rather than a learned contrastive head.
- Ablation gap × [[experiments/contrastive alignment]]: the Kriuk et al. bound says the cost of surf's structural prior is exactly the ablation gap measured in the experiment. Should the contrastive alignment experiment spec include an explicit "no-prior ablation" to bound this gap? That was already planned ([[claims/structure helps]] counterevidence), but now it has a formal interpretation: the gap IS the maximum information the prior provides.
- PhysCaP active probing × [[claims/iterative selection]]: PhysCaP plans multi-step physical probing before grasping. Surf's iterative selection is within-episode visual re-weighting. Can surf's iterative selection be interpreted as a "virtual probing" scheme — re-selecting tokens as if the agent were looking more carefully at a region without physically moving?
