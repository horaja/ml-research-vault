**Core**

- **Decoding Task Progress from VLA Representations** — `arXiv:2608.13474` — Bhardwaj et al., 2026-08-13 — Decodes task-progress signal from VLA residual stream; characterizes which layers encode progress toward task completion. Day 6 critical read: if progress is decodable from mid-layer activations, that's the hook point for SURF's scorer — directly answers where in the VLA architecture to inject the selection gate. *Must read: prerequisite for contrastive alignment spec architecture section.*

- **Attention from Action, for Action: Emergent Visual Bottlenecks for Policy Learning** — `arXiv:2608.13422` — Zhuang et al. — Seeker: task- and state-conditioned readout that derives visual attention bottlenecks purely from policy gradient signal, without explicit structural priors. If policy feedback alone induces task-relevant spatial attention, SURF's structural prior module may be redundant overhead. *Read before writing the differentiation section of the positioning note.*

- **Instruction-conditioned visual token sparsification for efficient VLM inference** — Cao et al. (Knowledge-Based Systems, 2026) — Journal publication directly titling SURF's proposed contribution; instruction-conditioned token selection on top of VLM inference. Must confirm whether this overlaps an existing reading list entry under a different citekey, or is new scope (KBS venue suggests static VQA efficiency, not action alignment). *Skim abstract immediately to establish how SURF differentiates.*

**Adjacent**

- **Think Proprioceptively: State-Grounded Visual Token Selection for VLA Policies** — `arXiv:2602.06575` — Wang et al. — ThinkProprio discretizes proprioceptive state into VLM-vocabulary tokens to gate visual token selection; proprioception as selection signal instead of language-only conditioning. Complementary to SURF's language conditioning and structural prior — proprioception is a gating signal SURF currently ignores. *Skim gating mechanism; relevant to prior module design.*

- **See2Think: Do Multimodal Models Really Use Intermediate Visual States?** — `arXiv:2607.26769` — Yan et al. — Empirically probes whether MLLMs actually consume intermediate visual encoder outputs before LLM fusion. If intermediate visual states are largely bypassed, SURF's assumption about injecting a scorer at visual-encoder output may hook into a layer the LLM ignores. *Skim key empirical finding; file under [[02-projects/surf/claims/efficiency without collapse]].*

**Horizon**

- **Neural signatures of associational cortex emerge in a goal-directed model of visual search** — Pourrahimi & Bashivan (bioRxiv, 2025) — Goal-directed visual search model spontaneously develops associational cortex signatures; provides computational grounding for goal-directed routing beyond V4. Supporting evidence for [[02-projects/surf/claims/v4 relevance]] and suggests higher-order cortical areas, not just V4, are the relevant locus. *File as biological evidence.*

- **GaussianWAM: Distilling Geometry and Semantics from 3D Gaussian Fields into World-Action Models** — `arXiv:2608.24714` — Zhang et al., 2026-08-25 — 3D Gaussian field geometry distilled into world-action model representations for robotics; structural geometry as the prior input to action prediction. Horizon view of how geometry priors compose with policy — same structural argument as SURF but with richer 3D representation. *File as supporting evidence for [[02-projects/surf/claims/structure helps]].*

## questions

Carried forward from 2026-08-25:
- Does SURF need to beat E2S-Pruner on efficiency, generalization, or both? Positioning must be explicit before spec.
- TOWN-VLA collapse: does SURF's selection gate need to operate *before* instruction-tuning collapses attention, or can it be inserted post-hoc?
- Pointing-VLA achieves spatial grounding without token removal. Under what conditions does token removal add value beyond grounding alone?
- "Grounding Isn't Knowing": if VLMs bypass patch-level localization, is SURF optimizing a non-bottleneck for capable base models?
- Sigmoid attention mismatch: does SURF's scorer gate suffer the same soft-to-hard discrepancy? Should the gate use hard Gumbel-softmax from the start?
