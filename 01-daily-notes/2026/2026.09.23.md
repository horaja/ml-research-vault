# 2026-09-23

## opener

ThinkProprio breaks a load-bearing assumption in SURF: that language instructions are the primary conditioning signal for visual token selection. It uses discretized proprioception tokens jointly with instruction to gate patches before VLM computation, and finds proprioception carries more action-relevant signal than the instruction for contact-rich manipulation. This directly challenges the "language helps" framing — if robot state dominates, instruction-conditioned patch scoring may be the weaker prior. The Conditional Removability paper reinforces that single-shot scoring (importance, redundancy) is underspecified: removability is conditioned on representation depth and deletion set composition. Both together tighten the design question for SURF's scoring stage and support "iterative selection" as load-bearing rather than optional.

Positioning note is day 29. Two direct VLA token-pruning papers (ThinkProprio, TADP) appeared this cycle. Write the note.

## papers

### digest (auto)

**Core**

- Instruction-conditioned visual token sparsification (Cao et al., Knowledge-Based Systems; citekey TBD). Applies language instruction to score and sparsify visual tokens at VLM inference time. Validates the "language helps" mechanism in a non-VLA setting, without a structural or geometric prior. Check: does sparsification operate on raw patch tokens or post-encoder features, and does the objective transfer to action prediction?

- ThinkProprio (Wang et al.; citekey TBD). Discretizes proprioception into VLM-vocabulary tokens; uses them jointly with instruction to gate visual patches before VLM computation. Reports proprioception alone carries more gating signal than instruction for contact-rich tasks. **Directly challenges SURF's language-only conditioning.** Design question: does SURF need joint instruction+state conditioning, and does the structural prior still add independent signal over robot state?

- Conditional Removability (He et al., arXiv 2026). Importance and redundancy criteria don't fully characterize safe token removal; removability is conditioned on representation depth and the surrounding deletion set. Same tokens removed at different layers produce different downstream perturbations; changing deletion context at fixed depth changes which tokens are safe. **SURF implication:** one-shot top-k scoring at a single layer is theoretically underspecified. Iterative/coarse-to-fine selection addresses this by construction — supports the "iterative selection" claim.

**Adjacent**

- TADP (Lin et al., IEEE ERTCS 2025; citekey TBD). Training-free dynamic VLA token pruning: estimates task-conditioned importance after early vision-language interaction, decouples main/wrist-view budgets, reuses keyframe scores under temporal consistency, refreshes budgets online. Poster at embedded systems venue — evaluation scope likely narrow. Direct comparison baseline for SURF's efficiency module.

- Digital Foveation (Caccavella et al.; citekey TBD). Saliency-driven fixation selection + high-res foveal + low-res context + semantic accumulation for efficient dense segmentation. Biological foveation as compute principle; uses saliency rather than structural or language-conditioned prior. Comparison point for saliency-based vs. structure-based region selection in SURF's prior module.

- Beyond Attention or Similarity (Zhang et al., NeurIPS; citekey TBD). Attention-based pruning retains duplicates; similarity-based pruning ignores instruction relevance. Proposes maximizing conditional diversity: retain tokens that jointly cover high-attention regions and minimize redundancy conditioned on instruction. Threatens SURF's patch scoring if it uses attention without diversity correction — check whether contrastive alignment objective induces diversity implicitly.

**Horizon**

- All-Topographic Neural Networks (Lu et al., Nature Human Behaviour; citekey TBD). End-to-end networks develop topographic organization; predict cortical response patterns and behavioral similarity data. Computational evidence that topography emerges from local spatial constraints rather than hand-coded convolution. Supports [[claims/v4 relevance]]: if topography is learnable and computationally motivated, V4-derived shape maps are a principled prior.

- V4 Single-Cell Characterization (Willeke et al., bioRxiv; citekey TBD). DNN models of V4 single-cell tuning in natural image space confirm topological clustering of shape-selective units. Read alongside @jiangComputationalConstraintsUnderlying for the joint claim: V4 is both topographically organized at the map level (Jiang) and shape-selective at single-cell resolution (Willeke).

## questions

- If proprioception outperforms instruction as a visual gating signal (ThinkProprio), what does instruction conditioning uniquely contribute? Is there a task category — language-specified goals, novel objects, long-horizon reasoning — where instruction dominates state?
- Conditional removability is depth-conditioned: does this apply to ViT patch tokens before they enter the LLM trunk, or only within LLM layers? Which layer is SURF's selection intended to operate at?
- Does TADP's keyframe score reuse assumption break for dynamic grasps where the workspace changes frame-to-frame?
- Does conditional diversity (Beyond Attention) subsume the structural prior, or is shape-structured selection orthogonal to diversity maximization?

## risks

- ThinkProprio may occupy the "state-conditioned visual selection" slot; if both SURF and ThinkProprio appear at the same venue, differentiation rests entirely on the structural prior axis — that axis needs to be validated before submission
- Conditional Removability shows one-shot scoring is theoretically weak; if SURF uses single-shot pruning, "iterative selection" must be explicitly positioned as the design response to this weakness
- Three competing VLA token-pruning papers this week (ThinkProprio, TADP, Conditional Removability) — convergence signal; positioning note is overdue
