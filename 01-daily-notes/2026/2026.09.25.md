# 2026-09-25

## opener

Friday, September 25. Positioning note is day 31 — no more valid deferrals.

Three papers today sharpen the positioning note agenda to concrete, answerable questions.

**ResPrune** is a new entry on the "language helps" axis: text-conditioned subspace reconstruction prunes visual tokens by greedily selecting those that minimize reconstruction error of a text-conditioned residual. It is training-free, operates before the LLM trunk, and outperforms importance/redundancy baselines. The forced question: what does SURF's structural geometric prior add that subspace reconstruction cannot provide? If ResPrune already captures instruction-relevant spatial content through text conditioning alone, the line-drawing prior is a redundant signal — unless it provides information that is orthogonal to what the text encodes (contact geometry, reachable workspace structure, object boundary density in regions the instruction does not name).

**PosA-VLA** independently validates SURF's core diagnosis — spatially uniform perception in VLAs produces redundant, unstable actions — but addresses it via pose-keypoint anchor attention. The differentiation axis is now sharper: both SURF and PosA-VLA fix the same problem with structural anchors; the difference is whether those anchors come from a pre-deployment geometric prior (line drawings, no robot data) or from a detected pose (requires scene observation at inference time). PosA-VLA's anchor requires a pose detector; SURF's prior requires only the input image's structure. This is a concrete data-cost and generalization comparison.

**The Alignment Illusion** is the hardest result: across 13 MLLMs from five families, replacing projector-output visual tokens with noise barely changes layer-wise visual-text similarity scores. Cross-modal alignment as measured by scalar similarity is architecture-driven, not content-driven. This threatens both "language helps" and the ResPrune mechanism: if high alignment score does not indicate content-level integration, instruction-conditioned token scoring may be scoring architecture artifacts. For SURF, this means the "language helps" claim needs a test that does not rely on attention/similarity scores as a proxy for relevance — the proxy may not be what it measures.

The three papers together define the positioning note's structural-prior section: (a) does structural geometry outperform text-conditioned subspace reconstruction (ResPrune comparison), (b) do line drawings outperform pose anchors on pre-deployment tasks where no robot data is available (PosA-VLA comparison), (c) what does instruction conditioning contribute if cross-modal alignment is architecture-driven (Alignment Illusion counterevidence against ResPrune and "language helps"). All three are addressable claims, not open-ended speculation. Write the note today.

**core**

- [ResPrune: Text-Conditioned Subspace Reconstruction for Visual Token Pruning in Large Vision-Language Models](https://www.semanticscholar.org/paper/d8d6855727d59b8f55efe9cade6191b073037d6a) — Xu Li, Yi Zheng, Yuxuan Liang et al. · arXiv · S2 keyword
  Training-free VT pruning via greedy subspace reconstruction minimizing text-conditioned residual error; outperforms importance/redundancy baselines without structural prior. New entry on the instruction-conditioned axis: language alone selects an informative token subset. For SURF, the comparison experiment is now defined: equal token budget, same VLA backbone, ResPrune (subspace) vs. SURF (structural geometry + language) — does the structural prior add task success, or is the language condition sufficient?

- [PosA-VLA: Enhancing Action Generation via Pose-Conditioned Anchor Attention](https://www.semanticscholar.org/paper/d77a24298f448ff9f6aeabec20137aebeb4534e9) — Ziwen Li, Xin Wang, Hanlue Zhang et al. · arXiv · S2 keyword
  Identifies spatially uniform VLA perception as the source of redundant action trajectories; fixes it with detected pose-keypoint anchors that gate cross-attention. Same diagnosis as SURF, different fix: pose anchors (requires pose detector at inference) vs. line-drawing prior (pre-deployment, no robot data). The OOD question is concrete: do pose anchors break on novel objects/scenes where the pose detector fails, and does the line-drawing prior generalize where pose detection does not?

- [World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation](https://www.semanticscholar.org/paper/70002131c142ad387f1d7ff2291ea9f27672d562) — Yuhao Pan, Haosong Peng, Zhengsheng Zhang et al. · S2 keyword
  Anticipates wrist-local interactions from global task context; treats main-view and wrist-view as distinct observation roles with predictive wrist modeling. Relevant to TADP's wrist-view budget decoupling comparison axis: W2-VLA decouples views via future-state prediction, TADP via keyframe score reuse. For SURF: should the structural prior be applied independently per view, or jointly, and does wrist-view require a different prior than main-view (contact geometry vs. workspace layout)?

**adjacent**

- [AdaVSkip: Adaptive Visual Token Skipping Across Layers For Efficient MLLMs Inference](https://www.semanticscholar.org/paper/f7888f151de801ebba275622640793848baabfe4) — Yu-Yao Sun, Tao Deng, Shuang-Hua Li et al. · S2 recommend
  Exploits vertical token redundancy across transformer layers adaptively per input and per module type (self-attention vs. MLP); outperforms fixed-layer skipping. Practical instantiation of Conditional Removability's theoretical result: the safe drop set is depth-dependent and input-dependent, not fixed. For SURF: if adaptive layer-selection beats fixed-layer, the selection layer for SURF's pre-computation structural scoring is a design choice that should be validated, not assumed.

- [TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks](https://www.semanticscholar.org/paper/ddc1b9474023a64805716fae9465aec022379d2a) — Zhihang Cao, Howard Ji, Kevin Zhang, Fei-Fei Li, Jiajun Wu et al. · S2 keyword
  Visual tracks (image-space point trajectories) as embodiment-agnostic conditioning signal for robot world models; eliminates the weak alignment between raw robot actions and image-space visual changes. Complements "Attention from Action, for Action" from a world-model angle rather than a bottleneck angle. For SURF: if structural line-drawing priors identify high-density boundary regions, do those regions overlap with the high-motion visual-track regions that TrAct identifies as task-relevant? This overlap test is a proxy for whether the structural prior captures motion-relevant structure.

- [The Alignment Illusion in Multimodal Large Language Models](https://arxiv.org/abs/2609.30210v1) — Hong-Han Wang, Yuntao Wang, Hu Ding · arXiv
  Replacing projector-output visual tokens with noise barely changes layer-wise visual-text similarity scores across 13 MLLMs (0.5B–72B); cross-modal alignment as measured by scalar similarity is architecture-driven, not content-driven. Controlled intervention confirms the metric is a measurement artifact. Directly threatens [[claims/language helps]]: if language-visual alignment scores do not track content, instruction-conditioned pruning based on these scores may not select task-relevant patches — it may select patches that are high-scoring due to positional or architectural regularities instead. The alternative test: does task success drop when instruction conditioning is removed at equal token budget?

**horizon**

- [Investigating action topography in visual cortex and deep artificial neural networks](https://www.semanticscholar.org/paper/c87a943995f33c4efc8a3b64d9c2358e3d314649) — Davide Cortinovis, Nhut Truong, H. P. Op de Beeck, S. Bracci · bioRxiv · S2 keyword
  fMRI finds action-selective topographic organization in left lateral occipitotemporal cortex: action properties of body-parts and objects predict neural response patterns beyond animacy and real-world size. Action is a distinct organizing axis for visual cortex topography. Supports [[claims/v4 relevance]] at an action-specific level: not just mid-level shape selectivity in V4, but action-relevant topography in higher visual areas. If action topography is empirically confirmed in visual cortex, the V4-derived structural prior may be capturing action-relevant spatial structure by construction.

- [TDSNNs: Competitive Topographic Deep Spiking Neural Networks for Visual Cortex Modeling](https://www.semanticscholar.org/paper/5f720e2aa2eb214f3c7bdf8a0bad0c8a01202f54) — Deming Zhou, Yuetong Fang, Zhao-Rui Wang, Renjing Xu · AAAI · S2 keyword
  Competitive lateral inhibition in spiking NNs drives topographic organization; temporal dynamics (missing from conventional ANNs) improve object recognition and biological fidelity for visual cortex modeling. Provides the computational mechanism for how V4 topographic structure emerges from local competitive constraints — not from explicit topographic training objectives. For SURF: the topographic prior over V4 shape maps may not need to be hand-engineered; competitive local learning could derive it, which has implications for whether the prior can be learned online.

## questions

- PosA-VLA: do pose-anchor VLAs fail on novel objects or scenes outside the pose detector's distribution? Does the data-free geometric prior generalize where pose detection does not?

New from today:

- TDSNNs: can SURF's structural prior be derived from competitive local learning rather than fixed V4-derived maps? Is a learned topographic prior better than a hand-specified one?
