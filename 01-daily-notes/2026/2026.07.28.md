Tuesday, July 28. Contrastive alignment spec unwritten — 22 weeks. GSPA unread — day 45. "When Attention Collapses" (STS) unread — day 34. Visual Access Boundaries unread — day 14.

**RoboPCA** (Xiao et al.) is the most actionable paper from today's digest. AffordSim (7/26) annotates task-required *contact regions*; RoboPCA predicts both contact regions and *contact poses* from human demos, jointly. This matters for [[claims/structure helps]]: if surf's line-density prior co-locates with contact regions but not contact poses, the structural prior approximates *where* to contact but not *how to approach* — a specific and informative limitation to know before writing the spec's evaluation section. The diagnostic is a direct extension of the AffordSim co-location test: run RoboPCA on LIBERO frames, run surf's line-density heatmap on the same frames, compare both contact-region and contact-pose-axis overlap.

**Top-down perceptual inference** (Csikor et al.) formalizes the biological circuit for iterative visual refinement: feedback connections from higher areas to V1/V2 transmit predictions, and only prediction errors propagate forward. This is the computation [[claims/iterative selection]] is implicitly approximating at the token level — allocate additional visual compute only to patches where the current representation is surprising given the model's current belief. The Csikor model provides a formal stopping criterion: stop iterating when prediction error at the candidate patches drops below a threshold.

Write the spec.

- [DeVA: Decoupled Video-Action Model with Physical Guidance for Robot Policy Learning](https://arxiv.org/abs/2607.24159v1) — Zhang et al. · arXiv 2026

For [[claims/structure helps]]: the world model's prediction residual — visual patches that change causally at action events — is a new ground-truth signal for co-location testing, independent of ViTacWorld's tactile channel (7/27) and motion-structure (7/26). **adjacent**

- [Focus-Scan-Refine: From Human Visual Perception to Efficient Visual Token Pruning](https://www.semanticscholar.org/paper/a1047da25d280a53cc064ab3877b280a707f78b0) — Tong et al.
  Three-stage training-free token pruning mimicking human foveation: focus (salient region localization) → scan (global context reintegration) → refine (high-res recovery). Competes with surf's structural prior without using any geometric features — pure saliency + context. The diagnostic: does FSR's focus stage select the same LIBERO contact-event patches as surf's line-density prior? Agreement means saliency already captures the structural signal; disagreement shows the prior selects contact-geometry tokens that attention-based saliency misses.

- [VQVLA: A Motion-Aware Vector Quantization Framework with Centroid Reuse for Efficient VLA Inference](https://arxiv.org/abs/2607.24148v1) — Song et al. · arXiv 2026
  Motion-aware VQ for efficient VLA inference: detects motion-relevant regions and preserves their tokens through quantization, discarding static-background tokens. Competing efficiency approach using temporal motion signal where surf uses structural geometry. Same co-location diagnostic as Self-Supervised Structured Dynamics (7/26): do motion-VQ-preserved tokens and surf's line-density tokens agree at LIBERO contact events? Agreement collapses the motion vs. structure distinction; disagreement shows structural prior identifies contact geometry that motion signal misses.

- [Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation](https://www.semanticscholar.org/paper/10986d9ca0afde4db9a2b963ddfa57a6c2a09848) — Qu et al. · S2
  Two memory types in VLA: task-level latent memory (episodic, long-horizon) + reactive latent memory (step-level, within-execution). Adjacent to [[claims/iterative selection]]: the dual-memory architecture implicitly defines two granularities at which visual re-allocation might be triggered — task-memory update signals coarse re-orientation (what to look for?), reactive-memory update signals fine patch re-allocation (exactly which tokens?). The per-granularity stopping criterion could formalize the two-level trigger that [[claims/iterative selection]] currently leaves unspecified.

**horizon**

- [Top-down Perceptual Inference Shaping the Activity of Early Visual Cortex](https://www.semanticscholar.org/paper/6d34bc84826ed09fe3579539e126bfd8ef26ea8d) — Csikor et al.
  Predictive coding model of top-down feedback from higher visual areas to V1/V2: feedback transmits predictions; only prediction errors propagate forward; this reduces effective visual compute by filtering predictable content. For [[claims/iterative selection]]: the Csikor circuit is the biological implementation of surf's budget policy — allocate additional visual compute to patches where prediction error exceeds threshold. The stopping criterion ("prediction error ≤ threshold → stop") is exactly what the budget policy needs, grounded in a concrete neural mechanism.

- [Diffusion-based Stimulus Optimization Reveals Functional Organization Across Higher Visual Cortex](https://www.semanticscholar.org/paper/1dc7def9a20d1dab6e5b64ac46705eede7e28dc9) — Henderson et al.
  Maps fine-grained functional organization of higher visual areas (V4, LOC, V3AB, EBA) by synthesizing preferred stimuli via diffusion model (BrainDiVE). Data-driven approach to characterizing which visual features each cortical area is tuned for. For [[claims/v4 relevance]]: extends Willeke et al.'s (7/26) single-cell V4 characterization to whole-area functional maps across the visual hierarchy — if the shape-vs-texture domain organization Jiang et al. model in V4 extends into adjacent areas, the dispersity prior may apply more broadly than V4 alone.

Does the surf budget policy operate at the task-level (re-allocate when long-horizon task phase changes) or at the reactive-level (re-allocate when step-level visual residual is high)? - Csikor × [[claims/iterative selection]]: The prediction-error threshold in Csikor's model defines when early visual areas need feedback-triggered refinement. What is the surf analog — prediction error in which representation, and how does it map to "allocate additional visual tokens"? The Bayesian stopping criterion from Predictive Coding Meta-RL (7/26) + the Csikor circuit together might give a grounded per-patch reallocation rule.
