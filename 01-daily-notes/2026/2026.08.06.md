**Mind-VLA** (Ding et al., arXiv 2608.04633) is today's most strategically important paper. Existing VLA methods that align with 3D geometry do so instruction-agnostically — the whole scene is aligned uniformly, regardless of which object the instruction specifies. Mind-VLA makes the alignment instruction-conditioned: it identifies the target object designated by the language instruction and aligns only that object's 3D spatial region. This is the first VLA paper to instantiate [[claims/language helps]] specifically in the 3D geometry alignment space — it is a direct competing method. The threat is structural: Mind-VLA achieves language-conditioned spatial selection without a structural geometry prior (line density, sketch), relying instead on instruction-grounded 3D object localization. The differentiation question is whether surf's structural prior provides qualitatively different selection beyond what instruction-conditioned 3D localization already captures — specifically, whether 2D structural edge density identifies action-relevant patches that 3D object alignment misses (e.g., affordance boundaries not coincident with the target object's bounding volume). Must read before writing the differentiation section of the contrastive alignment spec.

**DreamWAM** (Yuan et al., arXiv 2608.04996) provides the strongest motivational argument yet for non-RGB prediction in world-action models. It names the exact nuisance sources conflated in RGB space — texture, illumination, background, viewpoint — and argues WAMs should predict action-relevant state in a representation that discards these sources. This is a precise articulation of the motivation for surf's structural geometry prior: line drawings and edge maps discard texture, illumination, background, and viewpoint variation while preserving the contour geometry that defines affordance boundaries. DreamWAM's argument applies directly to surf's token selection problem — if the token scorer operates on RGB features, it must distinguish action-relevant structure from these nuisance sources; if it operates on structural features, the entanglement is avoided. Clearest available external validation of surf's motivation.
