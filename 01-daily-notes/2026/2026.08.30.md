**core**

- [Think Proprioceptively: State-Grounded Visual Token Selection for VLA Policies](https://www.semanticscholar.org/paper/2ce0a7201ebc0b4804a7f28d3536338e57e5c345) — Wang et al. · arXiv
  Proprioceptive state directs visual attention; the model learns which tokens are task-relevant by grounding instruction understanding in robot state rather than visual-side structural or language signals. Direct competitor to [[claims/language helps]] and [[claims/structure helps]]: if state alone suffices for token selection, SURF's contrastive prior needs to show that structure + language adds beyond what proprioception already provides. Baseline to add to the positioning note.

- [Depth Matters: Language-Guided Spatial Representation Learning for Robot Manipulation](https://www.semanticscholar.org/paper/d6087ec299513c92af00e2061701d128aa135681) — Zhu et al. · CAA
  Depth + language as a jointly-guided spatial representation for manipulation. Directly addresses the depth vs. line-prior axis that [[claims/structure helps]] must argue: if depth already carries the relevant 3D-geometric signal, SURF's line-prior argument (cheaper, no depth sensor, composable with language) needs to be explicit. Read before the positioning note.

- [FocusUI: Efficient UI Grounding via Position-Preserving Visual Token Selection](https://www.semanticscholar.org/paper/022a6b853a918ddaa7201b40e48d566fc797ed16) — Ouyang et al. · arXiv
  Token selection that explicitly preserves positional structure for UI grounding. Directly relevant to the @huangNuwaMendingSpatial2026 concern: attention-score pruning erodes the positional-interaction spatial frame. If FocusUI's position-preserving mechanism solves this for UI grounding, the same design principle may apply to manipulation. Read the position-preserving mechanism before finalizing [[experiments/contrastive alignment]] architecture.

**adjacent**

- [Learning to Act While Waiting: RL Finetuning of Generalist Robot Policies Under Inference Latency](https://www.semanticscholar.org/paper/6465865e98dd80d4ff51fc50a13f2d65e732453c) — Zhu, Mees, Levine et al. · arXiv (s2_author)
  RL finetuning of VLA policies that must act during the long inference window of large models — latency as an action-space problem, not just an efficiency metric. Complements FlashVLA (async decoding) and SURF (token reduction): three orthogonal latency axes. SURF's positioning note should acknowledge this framing: SURF reduces the compute cost per inference step; latency policies reduce the damage from slow inference; FlashVLA decouples encoding from action frequency.

- [TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks](https://www.semanticscholar.org/paper/ddc1b9474023a64805716fae9465aec022379d2a) — Cao et al. · arXiv
  Visual tracks (pixel trajectories) as an intermediate representation between robot control and world model prediction; argues actions are embodiment-specific and weakly aligned with image-space change, while visual tracks are not. Adjacent angle on "what is action-relevant in the visual signal" — if motion tracks are the relevant signal for manipulation, SURF's structural priors (static line density) may miss the temporally-dynamic relevance component. Skim method.

**horizon**

- [Neural signatures of associational cortex emerge in a goal-directed model of visual search](https://www.semanticscholar.org/paper/fe2b65fab39706ed38f49423aec299bc32a28972) — bioRxiv
  Closed-loop perception-action model of goal-directed visual search that produces associational cortex signatures; models the active loop between sensory input and task-driven behavior. Directly motivates SURF's task-conditioned selection framing at the computational neuroscience level: goal-directed attention is a closed-loop policy, not a feedforward filter. Relevant to [[claims/iterative selection]]: the horizon paper grounds the "refine based on intermediate evidence" idea in how associational cortex closes the perception-action loop.
