**Focus-Scan-Refine** (Tong et al., 2026-02) is the most methodologically parallel paper to surf's structural prior to date: a training-free 3-phase human-perception-inspired token pruning pipeline — focus on salient local evidence, scan globally for context, refine the selection. The Focus phase uses attention saliency rather than line density, making FSR the direct ablation baseline surf must beat on [[claims/structure helps]]: if FSR Focus patches and surf's line-density top-k co-locate at affordance boundaries and contact surfaces, surf's geometric prior is a proxy for saliency; if they diverge, that divergence is the differential claim.

**ReWiND** (Zhang et al., 2026-05, 61 citations) learns a language-conditioned reward function for robot manipulation without per-task demonstrations. At 61 citations, already canonical for language-as-reward in VLA training — and not previously surfaced in this digest. The connection to surf: ReWiND uses language to score visual observations as rewarding (trajectory-level); surf proposes to use language to score visual tokens as task-relevant (token-level). Both are language-conditioned visual interpretation problems; the operative difference is granularity, not mechanism.

## questions

- FSR × [[claims/structure helps]]: FSR's Focus phase uses attention saliency for local patch selection; surf uses line density. On LIBERO manipulation frames, do FSR Focus patches and surf's line-density top-k co-locate at affordance boundaries and contact surfaces? If yes, structural geometry is a faster proxy for saliency — the claim is computational, not representational. If they diverge, the divergence pattern (e.g., line density captures edge structure around handles that attention misses) is the empirical differential claim.
- StellaVLA × structural prior composability: StellaVLA's structured demo conveys task goal, spatial context, and affordance reasoning. Can surf's line-density token selection ground the spatial context that StellaVLA's demo provides — "here are the geometrically informative patches from your current scene, matching the spatial context from the retrieved demo"? This would make surf composable with StellaVLA rather than competing.
- ReWiND × [[claims/language helps]] shared representation: ReWiND's language-conditioned reward model scores visual observations for task progress. Surf's scorer selects patches based on task-relevance. If both are solved by a common language-conditioned visual encoder, surf's scorer could serve dual roles (token selection + reward labeling), providing a free training signal. Does ReWiND's reward model attend to spatially localized features (contact regions, object positions) that correspond to surf's selected patches?
- ContactGuard × [[claims/iterative selection]] trigger: ContactGuard predicts pre-contact failure probability from the action plan. Can this serve as surf's iterative selection trigger — "predicted failure → reallocate visual budget to the contact region"? ContactGuard uses an action-conditioned world model; TEMPO (day 7) constrains that no gradient flows to the VLM backbone from such models. Is ContactGuard's world model compatible with TEMPO's frozen-backbone constraint?
- Theory of Space × active perception formalism: Surf's structural prior is a passive one-shot spatial belief initialization. Is this a degenerate case of Theory of Space's active exploration, or a fundamentally different mode? If line-density patches constitute a sufficient spatial belief for the task, active exploration is unnecessary; if not, iterative spatial querying ([[claims/iterative selection]]) is required — formalizing when the one-shot prior is insufficient.
