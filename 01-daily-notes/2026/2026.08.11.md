## opener

Tuesday, August 11. Contrastive alignment spec unwritten — 30 weeks. GSPA unread — day 60. "When Attention Collapses" STS unread — day 48. Visual Access Boundaries unread — day 28. AtVLA unread — day 10.

Two papers today sharpen the competitive landscape for the spec's token-selection section in ways that cannot be addressed without reading them. **ThinkProprio** (Wang et al., S2 2026-02-06) adds proprioceptive state as a third gating signal for visual tokens alongside language and structure — discretizing robot joint state into VLM-vocabulary tokens and using them jointly with the instruction to prune patches before VLM compute. This is a direct baseline surf's ablation design has not accounted for. **VLA-IAP** (Cheng et al., S2 2026-03-24) claims an explicit "geometric prior mechanism" for training-free VLA token pruning using "structural anchors" — the phrase is close enough to surf's vocabulary that the spec differentiation section cannot be written without understanding what VLA-IAP's geometric prior actually is. Neither paper is on the reading list.

On the biological side, **Cortinovis et al.** (2025-08-07) is the strongest direct fMRI grounding for surf's selection target yet: action is a key organizing factor in visual cortex topography, with high-level visual cortex areas clustering responses by action affordance. If the patches that matter for action form a spatially coherent structure in biological vision, surf's geometric prior is approximating exactly that structure.

## questions

- ThinkProprio × [[experiments/contrastive alignment]] ablation: ThinkProprio gates visual patches using proprioception + language jointly. Should the spec's ablation suite include a proprioception-only baseline (zero language, zero structural prior), language-only baseline (TRIPS configuration), structure-only baseline (line density without language or proprioception), and the full combination? The current spec design has language-only and structure-only but not proprioception-only. Is proprioceptive state a stronger gating signal than geometric structure on LIBERO manipulation frames, where robot state correlates with which objects are reachable?
- VLA-IAP × [[claims/structure helps]] differentiation: VLA-IAP's "geometric prior mechanism" preserves "structural anchors" using "semantic-motion alignment." Is their geometric prior a static spatial prior (like surf's line density) or a motion-derived saliency map that happens to correlate with structural boundaries? The "semantic-motion alignment" phrasing suggests motion + semantics, not structural geometry — but the paper must be read to verify. If VLA-IAP's geometric prior is motion-based (temporal difference, optical flow), surf's claim that V1-level structural priors (static, training-free) are sufficient is complementary, not competing.
- Cortinovis × [[claims/v4 relevance]] operationalization: Cortinovis et al. show action topography in visual cortex fMRI responses. Does this action topography map correspond to the spatial regions surf's line-density prior selects on LIBERO manipulation frames? Concretely: if surf selects the top-k tokens by line density, do those tokens co-locate with the V4/IT regions showing strongest action-topographic organization (per Cortinovis fMRI)? The @jiangComputationalConstraintsUnderlying digital twin might allow this test on manipulation-style stimuli.
- RoboTTT × efficiency framing: RoboTTT scales temporal context to 8K timesteps without proportional latency via test-time training. Surf's efficiency argument has been framed as "reduce spatial tokens per frame → reduce compute per step." If temporal context (not spatial redundancy) is the primary bottleneck for robot generalization, does surf's efficiency claim need to be repositioned? The two are not competing — spatial and temporal dimensions are orthogonal — but if the field accepts that temporal context is the hard constraint, the pitch needs to separate "reducing spatial compute" from "solving the temporal memory problem."
- Finzi et al. × biological hierarchy: Finzi et al. show stream specialization emerges from topographic spatial organization (spatial similarity, not task-specific objectives). Subcortical front-end (Piper et al., 8/8) grounds surf's line-density prior in V1-level processing. Cortinovis grounds surf's selection target in action topography in V4/IT. Finzi grounds the topographic organization principle itself. Together: V1 produces structural features (line density ≈ V1 edge response) → V4 selects action-relevant structural patches topographically (Cortinovis) → downstream behavior is mediated by the specialized stream (Finzi). Is this a coherent biological narrative for [[claims/v4 relevance]]? What evidence would falsify it?
