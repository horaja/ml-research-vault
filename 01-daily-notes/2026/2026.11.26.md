**core**

- [Cairn: Object-Centric 3D Trajectory Priors for Steering Frozen VLAs](https://arxiv.org/abs/2611.34914) — Kratimenos et al. · arXiv (Nov 2026)
  Keeps the VLA frozen and steers it using predicted 3D object trajectories from a lightweight prior module; achieves layout generalization without fine-tuning. Closest published analog to SURF's design philosophy (structural prior + frozen backbone), but using 3D kinematic priors instead of 2D V4 shape. Required for the positioning note competitor table: does Cairn's 3D trajectory prior select the same spatial regions as SURF's shape prior on tabletop manipulation? If yes, they're complementary; if not, differentiation is straightforward.

- [HOG-WAM: Improving Visual Robustness through Future Gradient Prediction](https://arxiv.org/abs/2611.34811) — Dong et al. · arXiv (Nov 2026)
  Adds future HOG (oriented gradient) prediction as auxiliary supervision to a world-action model. The HOG objective regularizes RGB features toward edge-and-gradient-aware representations that remain stable under visual corruption. Independent empirical support for [[02-projects/surf/claims/structure helps]]: gradient/orientation structure is not just a selection prior but a training-time inductive bias that improves robustness. Worth noting in the positioning note as a converging signal.

- [Focus Only on What's Important: Training-Free Focus Maps for Frozen Vision Transformers in Long-Video Object Segmentation](https://arxiv.org/abs/2611.34863) — Karipineni et al. · arXiv (Nov 2026)
  Gives a frozen DINOv3 ViT a training-free focus map: full resolution over tracked objects, coarser merging elsewhere. Protects only the previous frame's mask area and achieves close to full-resolution accuracy with 30-50% compute reduction. Near-direct analog of SURF's non-uniform token protection: task-conditioned spatial selection outperforms uniform merging even when the selector is training-free. Important baseline to cite in the positioning note.

**adjacent**

- [Dynamic Task Update Benchmark (DTU-Bench): Evaluating Runtime Task Adaptation in Robotic Manipulation](https://arxiv.org/abs/2611.34538) — Jiang et al. · arXiv (Nov 2026)
  Benchmarks 40 instruction revision scenarios across 7 update types (object swap, goal change, constraint addition, etc.) at 3 execution stages in LIBERO. Existing VLAs drop 20–40 pp under mid-task instruction updates. Provides an evaluation frame for [[02-projects/surf/claims/iterative selection]]: if selection is re-run when instructions change, DTU-Bench is a natural benchmark to show it matters.

- [PURA: Video Token Pruning via Unified Spatiotemporal Redundancy Assessment](https://arxiv.org/abs/2611.34521) — Sun et al. · arXiv (Nov 2026)
  Unified spatial+temporal redundancy assessment for video LLM tokens; removes the fixed compression-order constraint of earlier methods. Adaptive allocation between spatial and temporal pruning at inference time. For SURF's compression pipeline, PURA is the current state-of-the-art non-structural video token pruner — the bar to beat on pure efficiency without a spatial prior.

- [Distractor-Robust Reinforcement Learning via Variational Bisimulation (VIBES)](https://arxiv.org/abs/2611.34641) — Freed et al. · arXiv (Nov 2026)
  Replaces pixel reconstruction with an adversarial bisimulation objective that forces latent states to be indistinguishable iff they lead to the same policy outcomes. Directly provides a formal definition for "task-relevant token": a patch is task-relevant iff removing it changes the bisimulation equivalence class. This is a principled theoretical grounding for SURF's selection criterion that avoids the error-reliance gap identified in NoveltyGate.

**horizon**

- [Motion Beyond Pixels: Learning Future Visual Representations for Object-Centric Dynamics](https://arxiv.org/abs/2611.34644) — Zhao et al. · arXiv (Nov 2026)
  World model (MotionRep) that jointly predicts future DINO representations and 3D object flow, coupling semantic and geometric information at the object level rather than the pixel level. For SURF's selection criterion: if the ideal visual representation for action prediction is object-level (not pixel-level), then patch selection should preserve object-centric tokens — which supports the structural prior approach over attention-based or reconstruction-error-based selection.

- [Stranger Things: When Objects Appear Without Their Typical Neighbors](https://arxiv.org/abs/2611.34881) — Gairola et al. · arXiv (Nov 2026)
  Typicality bias in modern vision backbones: models recognize objects from their typical scene context rather than intrinsic visual features, even with ViT architectures. Direct relevance to SURF's OOD robustness claim: if SURF's target backbone has typicality bias, its patch importance scores may rely on context tokens rather than object structure tokens — a V4 shape prior, which scores structure independent of scene context, may specifically correct for this.
