**core**

- [AffordSim: A Scalable Data Generator and Benchmark for Affordance-Aware Robotic Manipulation](https://www.semanticscholar.org/paper/1adbe7f56d7a64a14e86c54f8156b0357ee8a4a9) — M. Li et al. · arXiv
  Task success in manipulation is determined by whether the robot contacts the *functional* region required by the action — not just any stable grasp. AffordSim provides scalable simulation-based task-contact annotations across diverse manipulation tasks. The direct evaluation for [[claims/structure helps]]: do surf's line-density heatmaps select the annotated task-contact region, or do they identify geometric edges that don't coincide with functionally required contact locations? Offers a concrete benchmark to run alongside LIBERO once the spec is written.

- [MoE-ACT: Scaling Multi-Task Bimanual Manipulation with Sparse Language-Conditioned Mixture-of-Experts Transformers](https://www.semanticscholar.org/paper/6882a0ece1703c2988a0d7e6b7c11ff8d23d26db) — K. Guo et al. · arXiv
  Sparse language-conditioned MoE for multi-task bimanual manipulation: different task instructions activate different expert subnetworks via sparse routing. This is [[claims/language helps]] at the module level rather than the token level — the same core mechanism (language → selective processing) implemented via expert routing rather than token scoring. The per-task activation profile (which experts fire for which instructions) is a direct template for surf's ablation table: do the same tasks that benefit most from language expert routing also show the largest gain from surf's instruction-conditioned token selection?

**adjacent**

- [Out of Sight, Still in Mind: Token Compression for Omni-LLMs](https://arxiv.org/abs/2607.21179v1) — S. Yoo et al. · arXiv
  Training-free visual token compression for Omni-LLMs (video + audio + text): identifies key frames via temporal redundancy detection, then spatially compresses each frame by saliency scoring. Adjacent competitor to surf's architecture in the multimodal domain — temporal redundancy + saliency without structural prior. The diagnostic: does temporal key-frame selection + saliency-based spatial compression cover contact-geometry regions at LIBERO manipulation events, or does structural line density find contact geometry that saliency misses?

- [Self-Supervised Learning of Structured Dynamics from Videos](https://arxiv.org/abs/2607.21576v1) — L. Knobel, A. Zisserman, Y. Asano · arXiv
  Disentangles camera motion from object motion in video via self-supervised learning, recovering a structured representation of each dynamics layer separately. For manipulation video, object dynamics (contact events, grasps) are the task-relevant signal; this paper learns that structural decomposition without labels. Ablation target for [[claims/structure helps]]: do motion-discontinuity-defined tokens (contact events = trajectory discontinuities) and line-density-defined tokens co-locate at LIBERO contact scenes? If yes, motion structure and geometric structure converge at contact events; if no, line density identifies geometry that motion structure misses.

**horizon**

- [Deep learning-driven characterization of single cell tuning in primate visual area V4 supports topological organization](https://www.semanticscholar.org/paper/f019f4561cd9689cdea12526e7464d3b242302a4) — K. Willeke et al. · bioRxiv
  DNN-driven characterization of single V4 neuron tuning with natural images confirms topological columnar organization — extending the known V4 columnar structure beyond parametric stimuli (orientation, spatial frequency) to complex natural scene responses. Adds biological evidence that V4's topographic shape/texture domain clustering (the basis of [[claims/v4 relevance]] and @jiangComputationalConstraintsUnderlying's dispersity measure) is a robust organizational principle, not an artifact of parametric stimulation. Key question: do the natural-image-tuned columns in Willeke et al. show the same shape-vs-texture functional domain arrangement that Jiang's SOM predicts?

- [Predictive Coding Enhances Meta-RL To Achieve Interpretable Bayes-Optimal Belief Representation Under Partial Observability](https://www.semanticscholar.org/paper/3c4fc079a1d4e8b51192a0a48054f6304f91b827) — P.-C. Kuo et al. · arXiv
  Predictive coding + meta-RL achieves interpretable Bayes-optimal belief representation under partial observability: the belief state compactly encodes what to expect next given observations, enabling near-optimal planning. Relevant to [[claims/iterative selection]]: if surf's per-step visual selection is a form of partial observability (the model sees a selected view, not the full scene), the Bayes-optimal stopping rule for surf's budget policy follows from the predictive coding belief update — stop refining when the predicted next observation's uncertainty drops below the cost of one more selection step. Provides a formal grounding for the iterative selection stopping criterion that is currently unspecified.

## questions

- AffordSim × [[claims/structure helps]]: AffordSim annotates the task-required contact region (not just stable grasps) for diverse manipulation tasks. Do surf's line-density heatmaps co-locate with AffordSim's functional contact annotations on the same scenes? Co-location positive confirms structural prior selects the functionally required region; negative means line density finds geometric edges that don't match task-required contact locations.
- MoE-ACT × [[claims/language helps]]: Sparse language-conditioned expert routing shows which task types gain most from language conditioning at the module level. Does the task-type gain profile from MoE routing match the gain profile that surf's instruction-conditioned token selection would show on the same task suite? If the same tasks benefit from language routing and language token selection, language conditioning is the consistent signal; if they diverge, the representations differ fundamentally.
- ReMo × surf: ReMo's key-frame selection uses temporal redundancy; its spatial compression uses saliency. On LIBERO contact tasks, do key-frame + saliency-compressed tokens cover the contact geometry that surf's structural prior selects? If yes, temporal+saliency subsumes structural prior; if no, surf's prior identifies contact structure that temporal redundancy and saliency miss.
- Self-Supervised Structured Dynamics × [[claims/structure helps]]: Motion-discontinuity regions in manipulation video (contact events = hand deceleration / object displacement onset) should co-locate with geometric contact structure. Do motion-structure-defined tokens and line-density-defined tokens select the same LIBERO contact patches? The comparison determines whether surf's line-drawing prior is approximating a motion-structure signal or capturing independent geometry.
- Willeke V4 × [[claims/v4 relevance]]: Willeke et al. characterize V4 column tuning with natural images — does the shape-vs-texture functional domain arrangement match Jiang et al.'s SOM prediction from artificial stimuli? If the natural-image DNN finds the same functional domains, the topographic map is a stable organizational principle that surf's dispersity prior can rely on.
