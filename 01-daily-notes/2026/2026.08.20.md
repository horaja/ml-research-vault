- [GS-VLA: Plug-and-Play Viewpoint Canonicalization for Frozen VLA Policies via Gaussian Splatting](https://arxiv.org/abs/2608.19066v1) — arXiv · 2026-08-19
  Relevance: A 4M-param 3DGS canonicalizer prepended to a frozen VLA recovers ~90% of the success loss from camera shifts on LIBERO, without retraining. This is the frozen-backbone geometric preprocessing approach surf has not yet formalized — operating in 3D observation space where surf operates in 2D token space. If GS-VLA and surf's structural prior select for the same geometric invariant (object surface structure near contact zones), the approaches are composable; if not, GS-VLA threatens [[claims/structure helps]] by showing geometric preprocessing can be done downstream of token selection entirely.

- [CompCPZ: Preserving Multi-Modal Intent in Language-Guided Robot Manipulation](https://www.semanticscholar.org/paper/ae220cdbf7931b90a107bc4e638a2bed4edc13c3) — S2 · 2026-08-18
  Relevance: Exposes the structural failure mode where language-conditioned policies collapse disjunctive instructions into a single connected action set, missing feasible modes. Relevant to [[claims/language helps]]: surf's contrastive scorer conditions at the patch level on the full instruction; if the instruction encodes disjunction or conditional spatial structure, a patch-level contrastive score may lose the compositional structure that CompCPZ's algebraic layer preserves. Not about token selection — about what it means to correctly condition on language in the first place.

- [PartialBiGrasp: Inferring Hidden Local Geometry for Bimanual Grasping from Partial Views](https://arxiv.org/abs/2608.19188v1) — arXiv · 2026-08-19
  Relevance: Learns geometric features (thickness, edge structure, gripper clearance) implicitly via convolutional occupancy networks from partial point clouds, recovering graspable contact regions. Tests the "are contact regions recoverable from structural cues alone?" question (surf's questions.md) for 3D grasping. If hidden geometry can be inferred from partial 3D observations, the analogous 2D result would support surf's claim that line-density patches span the contact-relevant geometry.

**adjacent**

- [HiSC: Hierarchical Spatial Clustering Token Compression for Efficient 3D Scene Understanding](https://www.semanticscholar.org/paper/c7cf09351633e5c9c5c94ecfd49c6dd488c84222) — S2 · 2026-08-05

- [Seek to Segment: Active Perception for Panoramic Referring Segmentation](https://www.semanticscholar.org/paper/bf7ddadac319f394e48102c0c4a0eab1fd7f836b) — S2 · 2026-07-02

- [DA-WAM: Decision-Aligned Future Latents for Driving World Models](https://arxiv.org/abs/2608.19085v1) — arXiv · 2026-08-19
  Relevance: Makes future world model representations decision-informative rather than purely predictive via momentum encoder + action-conditioned predictor + factorized scorer. The "decision-aligned" criterion (representation co-evolves with planning objective) is the autonomous driving analog of surf's task-relevant token selection — both require that the feature space be aligned to downstream action quality, not just reconstruction fidelity. Reference for how to operationalize "task-relevant" as a training objective.

## questions

- GS-VLA × surf architecture: GS-VLA canonicalizes the 3D observation via novel-view synthesis before token processing. Surf selects which 2D tokens to process from the raw observation. Are these composable (first canonicalize, then select geometrically relevant patches)? Or does canonical-view synthesis render surf's line-density prior redundant (the canonical view already has the right geometry)? The answer determines whether surf should position as complementary to geometric preprocessing or distinct from it.
- GS-VLA × [[claims/structure helps]] baseline: GS-VLA uses 3DGS to synthesize canonical views; surf uses line drawings to score patch informativeness. Both are geometric preprocessing for frozen VLAs. If both achieve similar downstream performance, which is the principled approach for the general single-camera case (no depth, no stereo, no prior 3D reconstruction)?
- CompCPZ × [[claims/language helps]] failure modes: If surf's contrastive scorer assigns a patch a score based on similarity to the full instruction embedding, disjunctive or compositional instructions may produce a score that averages across the feasible modes (centroid collapse). Is this a real failure mode for LIBERO's instruction set, or are LIBERO instructions always unambiguous? If unambiguous, CompCPZ is adjacent; if not, it defines a failure mode surf's scorer must handle.
- PartialBiGrasp × [[claims/structure helps]] analog: PartialBiGrasp recovers contact geometry from partial 3D point clouds. If the analogous 2D result holds — that line-density patches in a manipulation scene span the contact-relevant geometry — this would provide empirical support for surf's prior. Testable: compute IoU between top-k line-density patches and ground-truth contact regions on LIBERO frames (cf. [[eval/baselines]]).
- Neural signatures × [[eval/gaze]]: Pourrahimi & Bashivan's saccadic model produces human-like scanpaths emergently. If this model's fixation sequence on manipulation frames matches surf's selected patches, that's converging evidence that line-density captures the geometrically informative regions that active visual search would identify. Testable after finding the paper in full.
