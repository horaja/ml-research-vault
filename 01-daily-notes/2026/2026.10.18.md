# 2026-10-18

## opener

Positioning note is day 54. The baseline landscape now has four distinct competing selection criteria occupying SURF's regime: proprioceptive state direction (ThinkProprio), action-consistent pruning (VLA-ACL), geometric stride retention (Spatial Scaffolds), and task-conditioned temporal compression (FastVLA). The positioning argument must distinguish SURF's line-drawing structural prior from all four on novel-object scenes — not just from attention-based or semantic pruning.

Today's digest sharpens two open questions simultaneously. **BridgeAfford** provides a direct evaluation frame for the affordance-coverage claim: language-guided 3D affordance grounding for novel objects tests whether instruction semantics alone can identify contact/interaction regions without geometric priors. The query-target semantic gap it addresses is exactly what SURF's structural prior is positioned to close — on novel objects where language-text statistics are absent, the prior covers what instruction-conditioned selectors miss. **SCMerge** arrives as a new spatial-structure baseline: it adds spatial positional consistency as a merging criterion alongside feature similarity, which is a weaker form of SURF's structural claim. The test: does line-drawing density add to positional-consistency-based merging, or does generic spatial structure subsume the signal from object contours?

**REKI** (2.4B VLA, public data only, LIBERO-Plus SOTA in its size class) is the new performance floor. SURF's contrastive alignment spec must now be measured against it.

Cao et al. is day 19. Read today.

- [SCMerge: Spatial-Consistency-Aware Token Pair Merging for Efficient Semantic Segmentation](https://www.semanticscholar.org/paper/936a05013a80465b6f7d4fb866607172230f634b) — preprint 2026-10-15
  Adds spatial positional consistency as a second merging dimension alongside feature similarity for ViT semantic segmentation; tokens that are both feature-similar and spatially proximate are merged preferentially. New baseline for [[02-projects/surf/claims/structure helps]]: spatial structure is now a competitive compression criterion, but it uses generic position, not object-specific contour geometry. The test: does SURF's line-drawing prior add to positional-consistency merging, or does spatial consistency subsume object-contour selection on manipulation scenes with novel objects? If they select the same tokens, SURF's structural advantage is limited to scenes where object geometry deviates from uniform spatial distributions.

- [REKI: Registering Knowledge in VLAs](https://www.semanticscholar.org/paper/9618438589a285b3c76687585111dda3e7d6f682) — preprint 2026-10-15
  A 2.4B VLA pretrained exclusively on public data; sets a new Pareto frontier on LIBERO-Plus, RoboTwin Clean2Rand, and RoboCasa365 — outperformed only by models roughly twice its size. New performance floor for [[02-projects/surf/experiments/contrastive alignment]]: SURF's structural prior must demonstrate additive gains over REKI, not just over OpenVLA. Check what visual tokenization strategy REKI uses — if it already applies geometric or spatial compression, the additive margin for SURF's prior narrows, but the baseline is set.

**adjacent**

- [DK-VLM: Geometry as Position for Spatial Reasoning in Vision-Language Models](https://arxiv.org/abs/2610.22356v1) — arXiv 2026-10-15
  Fuses 3D reconstruction features into visual token positions via Dual-Kernel Attention, improving 3D spatial reasoning in VLMs under limited spatial supervision. Adjacent to SURF: geometry-as-position (DK-VLM) and geometry-as-selection (SURF) are orthogonal interventions on the same underlying problem. If encoding geometric positions improves spatial reasoning, and SURF's selection focuses compute on geometrically structured regions, the two compose naturally — the positional encoding tells the model where structure is; the selection prior allocates budget to those regions.

- [Spark-0: Scaling Spatially Aligned Tactile Pretraining for Robot Dexterous Manipulation](https://arxiv.org/abs/2610.22342v1) — arXiv 2026-10-15
  Vision-tactile-language-action model (VTLA) that uses image-space contact maps derived from tactile sensing to spatially align touch with vision at pretraining time. Adjacent to [[02-projects/surf/claims/structure helps]]: contact maps are the ground-truth signal that SURF's geometric prior approximates — structurally dense patches (line drawings) should predict contact-relevant regions before contact occurs. Check whether Spark-0's contact maps co-locate with line-drawing-selected patches on the same manipulation objects; positive co-location would validate SURF's prior as a zero-contact-sensing proxy for tactile affordance.

**horizon**

- [High-dimensional population codes reveal interpretable and diverse features underlying visual perception](https://www.semanticscholar.org/paper/77d45b09e5b52550f7efd86e552605916a09849d) — S2 2026-09-11
  Extracts population codes from macaque V4/IT electrophysiology; automated method for representation interpretability/diversity; demonstrates via targeted ablations that interpretable representations have a causal role in downstream behavior. Direct evidence for [[02-projects/surf/claims/v4 relevance]]: if interpretable V4 features causally determine behavior (not merely correlate with it), SURF's line-drawing prior — which approximates mid-level shape features — has behavioral grounding, not only neuroanatomical motivation. The causal-role framing is a stronger claim than topographic organization: it says the features matter for what the animal does, which maps onto the action-relevance argument SURF needs to make.
