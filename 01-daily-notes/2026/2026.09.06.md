**core**

- [Instruction-conditioned visual token sparsification for efficient vision-language model inference](https://www.semanticscholar.org/paper/f881e97e2e88f5a8754e462891224c72428020af) — Cao et al. · Knowledge-Based Systems
  Direct instantiation of SURF's core mechanism in the VLM inference setting. No abstract available — read immediately to establish whether the structural approach, the language conditioning mechanism, or both overlap with SURF's design. Needed before positioning note is final.

- [TADP: Task-Aware Dynamic Visual Token Pruning for Efficient Vision-Language-Action Inference](https://www.semanticscholar.org/paper/57777db0ec2f567f3742d2d0cab4f1e00613e765) — Lin et al. · IEEE RTCSA
  Training-free dynamic token pruning for VLA: estimates task-conditioned visual importance after early vision-language interaction and prunes before the action head. No learned prior, no structural signal — pure importance estimation. Direct baseline challenge to SURF: if training-free task-conditioned pruning achieves competitive VLA performance, SURF's trained structural prior must earn its training cost via localization quality, held-out generalization, or structural specificity.

- [TARL: Learning task-adaptive visual-language relevancy for language-conditioned manipulation](https://www.semanticscholar.org/paper/78fa37093cd4c0f6cd64b78006220edbf8f05919) — Luo et al. · ICRSN
  Learnable relevancy refinement module that adapts frozen VLM priors using RGB-D observations for language-conditioned manipulation. Directly tests [[claims/language helps]] without a structural prior: if TARL's learned VL relevancy achieves task-aligned attention in manipulation, SURF must isolate what the line-drawing prior adds beyond learned relevancy alone. RGB-D input is a depth-based structural signal — compare against SURF's geometry-free line prior.

**adjacent**

- [History-Conditioned Spatio-Temporal Visual Token Pruning for Efficient Vision-Language Navigation](https://www.semanticscholar.org/paper/4755e2c70d9686aeb663bcb341c339a8edc6df33) — Wang et al. · arXiv
  Training-free spatio-temporal token pruning for VLN: uses execution history to inform which tokens survive across steps. VLN context, not manipulation — but the history-conditioned pruning design directly addresses the temporal-conditioning gap in SURF's spatial prior. Informs how history should enter SURF's selector without requiring a full TemporalFlow-style state tracker.

- [Gaze on the Prize: Shaping Visual Attention with Return-Guided Contrastive Learning](https://www.semanticscholar.org/paper/ac43acda376c1d2a4c79f236046064b9bb062df8) — Lee et al. · arXiv
  Return-guided contrastive objective to shape where a visual RL agent attends, foveation-inspired. The contrastive mechanism — pulling task-relevant spatial features toward high-return regions — is closely related to SURF's [[experiments/contrastive alignment]] design. Key question: return signal vs. language instruction as the contrastive supervision signal — for manipulation, language instruction is available; return signal requires environment interaction.

- [Look, Zoom, Understand: The Robotic Eyeball for Embodied Perception](https://www.semanticscholar.org/paper/2c0375bf1aaa5637453373a5bd9b267bfdaab26d) — Yang et al. · arXiv
  Active perception system deciding where to look and at what scale under pixel and spatial budget constraints in embodied AI. Resolution-adaptive foveation (sensor-level) vs. SURF's patch selection (token-level) — the two operate at different abstraction levels and may compose. Provides a resolution-adaptive baseline: does SURF's token-level pruning add beyond resolution-adaptive sampling at the same effective pixel budget?

**horizon**

- [Investigating action topography in visual cortex and deep artificial neural networks](https://www.semanticscholar.org/paper/c87a943995f33c4efc8a3b64d9c2358e3d314649) — Cortinovis et al. · bioRxiv
  Proposes action as a key organizing factor of high-level visual cortex topography (alongside animacy and real-world size); tests whether topographic DANNs capture this organization via fMRI. Directly extends [[claims/v4 relevance]]: if visual cortex is action-topographic (not just shape/texture-topographic), then SURF's structural prior grounded in V4 shape columns should predict which manipulation-action classes benefit most from structural selection — a testable link between biological topography and per-task prior quality.

- [Predictive processing as a scalable computational principle for embodied multitask intelligence](https://www.semanticscholar.org/paper/29e12a0e6c1e29b79e245665bfdd986bb5190547) — Idei et al. · Science Advances
  Hierarchical multimodal RNN grounded in the free-energy principle (predictive processing) handles multi-task embodied agents without task-specific modules. Architectural grounding for SURF's prior module as top-down prediction: if predictive processing scales to embodied multi-task settings, SURF's structural prior can be framed as a task-conditioned predictive prior over where action-relevant information should appear — theory rather than just inductive bias.
