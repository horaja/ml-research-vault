# 2026-10-10

## opener

Positioning note is day 46. S2 API recovered today after a 6-day outage — full candidate pool returned (keyword: 370, recommend: 71, author: 0 due to sort bug).

VLA-ACL (Du et al.) introduces action-consistent token pruning: tokens are scored by their direct contribution to the action head output rather than by semantic salience, reconstruction quality, or geometric structure. This is the second published method in two days (after COSTGRAD, 10/08) that frames token selection as explicitly optimizing for the control objective. Both methods converge on the same design principle — tokens that matter for planning/action, not prediction. SURF's structural prior is zero-shot and geometric; it cannot compute an action-consistency score without a deployed policy. The positioning note must address whether SURF's structural prior approximates action-consistency as an efficient proxy, or whether it selects a structurally-distinct but complementary token subset.

When Text Matters (Kang et al.) provides design-principle-level evidence for why text-guided token selection fails: high text-image similarity does not imply task relevance for the selected visual tokens, and standard contrastive metrics are poor proxies for downstream task performance in token selection. This is a direct critique of the mechanism SURF's contrastive prior uses for scoring. The failure modes must be read before finalizing the contrastive alignment spec language channel.

Compact Robot Policies isolates visual representation quality (not scale) as the key variable driving multi-task manipulation performance: fine-grained boundary and edge features carry more task-relevant information than broader semantic features. This is independent empirical support for [[02-projects/surf/claims/structure helps]] from a controlled ablation rather than a pruning experiment.

Cao et al. is day 11. Read today.

**core**

- [VLA-ACL: Action-Consistent Visual Token Pruning for Efficient Vision-Language-Action Models](https://arxiv.org/abs/2610.08133) — Du et al. · arXiv
  Scores tokens by their contribution to the action head output rather than semantic or reconstruction salience; action-consistent pruning outperforms attention-based and reconstruction-based selectors at the same compression ratio. This is the second control-objective-grounded selector in two days (cf. COSTGRAD, 10/08). Key question for [[02-projects/surf/claims/structure helps]]: do SURF's structurally-selected patches (geometric prior) overlap with action-consistent tokens, or do they capture complementary signal? If they diverge, SURF's prior selects the wrong tokens for control even if it is geometrically sound.

- [When Text Matters: Design Principles for Visual Token Pruning in Vision-Language Models](https://arxiv.org/abs/2609.34861) — Kang et al. · arXiv
  Systematic analysis of text-guided token selection: high text-image cosine similarity is a poor proxy for task relevance; naive contrastive token scoring fails on tasks requiring spatial reasoning and fine-grained alignment. Directly targets the mechanism SURF's contrastive prior applies. Required read before finalizing the language channel of the [[02-projects/surf/experiments/contrastive alignment]] spec — the failure modes Kang et al. identify constrain which contrastive objectives avoid the identified pitfalls.

- [Compact Robot Policies Need Fine-Grained Visual Representations](https://arxiv.org/abs/2610.08183) — Chen et al. · arXiv
  Controlled comparison isolating visual representation quality from model scale and architecture: fine-grained boundary and edge features drive multi-task manipulation performance more than coarse semantic features. Independent empirical support for [[02-projects/surf/claims/structure helps]] from a representation study (not a pruning experiment). Check: do the fine-grained features that drive performance correspond to the patch regions SURF's line-drawing prior selects?

**adjacent**

- [AIM: Intent-Aware Unified World Action Modeling with Spatial Value Maps](https://arxiv.org/abs/2604.11135) — Fan et al. · arXiv
  Learns spatial value maps encoding "where to interact" — the spatial distribution of task-relevant regions given a language instruction. The value map is a learned oracle for the spatial attention pattern SURF's structural prior attempts to approximate zero-shot. Check: does the value map's high-value region in manipulation scenes overlap with line-drawing/boundary patches? If yes, SURF's structural prior is a training-free approximation to AIM's learned spatial oracle.

- [Rethinking Visual Token Compression for Video Large Language Models: A Simple Yet Strong Baseline](https://arxiv.org/abs/2609.35394) — Zhang et al. · arXiv
  Demonstrates that simple frame-uniform sampling and token-uniform compression baselines match or outperform sophisticated video token selection methods on temporal reasoning tasks. Domain is video LLMs, not VLA — but the design principle transfers: before claiming compression quality, verify against simple baselines. Add to the [[02-projects/surf/experiments/contrastive alignment]] baseline table alongside Stride (Beyond Token Importance, 10/07): SURF's structural prior must beat both spatial-uniform (Stride) and content-agnostic-uniform (this paper's baseline).

- [World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation](https://arxiv.org/abs/2608.05369) — Pan et al. · arXiv
  Models future wrist trajectories conditioned on task language to guide what fine-grained visual information the wrist-view camera should capture; outperforms treating main-view and wrist-view as symmetric visual inputs. Relevant to SURF's structural prior design for close-range manipulation: task-conditioned future-state geometry is predictive of which structural tokens matter, consistent with [[02-projects/surf/claims/structure helps]] and the active vision framing.

**horizon**

- [Deep learning-driven characterization of single cell tuning in primate visual area V4](https://www.semanticscholar.org/paper/f019f4561cd9689cdea12526e7464d3b242302a4) — Willeke & Restivo et al. · preprint
  DNNs characterize single-neuron tuning in primate V4 at scale; results support a topographic organization of shape and texture selectivity columns. Independent empirical validation of the columnar structure model in @jiangComputationalConstraintsUnderlying; grounding for [[02-projects/surf/claims/v4 relevance]]. Check: do the shape-selective columns correspond to the edge/boundary regions the line-drawing prior extracts?

## questions

New from today:
- VLA-ACL: Do SURF's geometrically-selected patches (line-drawing prior) overlap with VLA-ACL's action-consistent tokens on manipulation scenes? If they select different tokens, structural priors and action-consistency select complementary visual information; if they align, SURF is an efficient zero-shot proxy for VLA-ACL's supervision signal.
- VLA-ACL: What does VLA-ACL use as an action-consistency proxy at training time — action-head gradients, attention scores from the action head, or a learned scorer? Does this scale to inference, or is it training-time supervision only?
- When Text Matters: What specific failure modes does it identify for contrastive token scoring — failure in the text-visual similarity metric itself, in the selection criterion, or in the downstream task objective? Which of these does SURF's contrastive alignment design inherit?
- Compact Robot Policies: Do the fine-grained visual features driving manipulation performance correspond to boundary/edge patches (consistent with the line-drawing prior) or to a different feature type (e.g., depth discontinuities, surface normals)?

Carried from 2026-10-09:
