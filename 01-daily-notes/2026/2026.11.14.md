**core**

- [PerturBot: Breaking Shortcut Priors in Vision-Language-Action Models with Perturbative Training](https://arxiv.org/abs/2610.04616) — Liu et al. · arXiv Oct 2026
  Perturbation augmentation + GroundingFscore evaluation framework for disentangling VLA decisions from spurious visual shortcuts. Empirically quantifies which VLA backbones are most susceptible and how much robustness perturbative training recovers. For SURF: validates the shortcut problem SURF addresses; PerturBot (data augmentation) vs. structural prior (SURF) are competing solutions to the same failure mode — both required as baselines for each other. GroundingFscore is a reusable eval metric for SURF's shortcut-robustness claims.

- [Don't Ask the LLM: Visual Token Pruning with Spectral Structure and Semantic Relevance](https://arxiv.org/abs/2610.38303) — Shin et al. · arXiv Oct 2026
  ST-Pruner: training-free, pre-LLM token selection combining spectral saliency (attention-independent structural signal) with inverted patch-text similarity via multiplicative fusion. For SURF: architecturally the closest existing design to SURF's selector — structural signal × language signal, pre-LLM, training-free. The critical comparison: does V4 shape structure (SURF's prior) beat spectral/SVD structure (ST-Pruner) for task-relevant patch selection on manipulation benchmarks? ST-Pruner is the baseline SURF's selector needs to beat.

**adjacent**

- [FastVLA: Task-Conditioned and Temporally Adaptive Visual Token Compression for Efficient Vision-Language-Action Models](https://arxiv.org/abs/2610.22146) — Xu et al. · arXiv Oct 2026
  Training-free task-conditioned token compression with per-timestep adaptive budgets; outperforms plug-and-play pruning baselines on manipulation tasks. For SURF: concurrent system showing task-conditioned token selection without a structural prior is already competitive — defines the [[claims/language helps]] baseline and sets the bar SURF's structural prior must clear.

- [$A^3$-VLA: Automatic Perception-Guided Attention Alignment for Robot Manipulation](https://arxiv.org/abs/2611.06447) — Zhang et al. · arXiv Nov 2026
  Derives task-specific fine-grained perceptual supervision from the manipulation process itself (not from language instructions or structural priors); improves multiple VLA backbones consistently. For SURF: third approach to the same problem — SURF (shape prior + contrastive alignment), FastVLA (task-conditioned feature scoring), A³-VLA (manipulation-process-derived supervision). A³-VLA's signal is what the action sequence encodes about visual relevance — the question is whether this overlaps with SURF's contrastive alignment target.

- [SVD-Prune: Spectral Vision Token Pruning under Extreme Compression](https://arxiv.org/abs/2611.02284) — Apedo et al. · arXiv Nov 2026
  Reframes token pruning as preserving dominant low-rank spectral structure (SVD leverage scores), not individual token importance; training-free. For SURF: validates structure-based pruning is the right direction; the spectral (mathematical) structure vs. V4 shape (biological) structure question — at extreme compression ratios, does shape structure generalize better than spectral structure on out-of-distribution manipulation scenes?

**horizon**

- [A topographic video model predicts the spatio-functional organization of the human visual system](https://www.semanticscholar.org) — arXiv Nov 2026 (S2 only — no arXiv ID in record)
  Extends topographic neural network modeling from static images + ventral cortex to dynamic video representations and full cortical organization; spatially arranges units on a simulated cortical sheet while preserving task performance and brain alignment. For SURF: if topographic V4 organization reproduces with video-domain stimuli (the actual input modality for VLA), the V4 shape prior operates on a representational basis consistent with the downstream action domain — extends @jiangComputationalConstraintsUnderlying from static images to the VLA setting ([[claims/v4 relevance]]).

## risks

- **Positioning note (day 81)**: Unread queue unchanged.
