## opener

Monday, September 7. Positioning note is day 13 — still unwritten. Five independent teams have now instantiated SURF's core mechanism in the past two weeks. Today's digest adds three more differentiators the note must address: proprioceptive-state gating of visual patches (ThinkProprio), action-supervised emergent visual bottlenecks (Attention from Action), and a quantitative grounding diagnosis showing exactly when and why visual localization fails in visuomotor policies ("What Matters, When?"). The positioning note can no longer describe SURF's mechanism without naming what separates the structural line-drawing prior from: (a) proprioception-gated selection, (b) action-supervised ROI derivation, (c) training-free importance estimation, (d) learned VL relevancy, (e) direct instruction-conditioned sparsification. Each of these occupies the same architectural slot with a different prior signal. The note must answer: under what conditions does the structural prior win, and what does it recover that none of these alternatives can?

S²Prune remains unread (day 13). "Attention from Action, for Action" is closely related to Seeker (both derive label-free ROIs from action trajectories without spatial annotation) and should be read before the positioning note is finalized.

**core**

- [Think Proprioceptively: State-Grounded Visual Token Selection for VLA Policies](https://www.semanticscholar.org/paper/2ce0a7201ebc0b4804a7f28d3536338e57e5c345) — arXiv 2026-02-06
  Discretizes proprioceptive state into VLM-vocabulary tokens and uses them jointly with the instruction to gate visual patches before VLM computation, steering attention toward task-relevant regions during closed-loop control. Occupies exactly SURF's architectural slot — visual patch gating before VLM — with proprioceptive state as the prior signal instead of structural line-drawing features; the two priors are independently motivated and may compose, or one may dominate in manipulation settings. Sharpens [[claims/structure helps]]: if proprioceptive state alone gates visual patches effectively, SURF must show that structural shape signals add localization quality beyond what robot state implies.

- [What Matters, When? Diagnosing and Improving Conditional Visual Grounding in Visuomotor Imitation Policies](https://arxiv.org/abs/2609.05376v1) — arXiv 2026-09-04
  Uses Action Chunking Transformers to show that visual localization targets change with manipulation phase and observed task state; policies fail not from insufficient capacity but from failure to condition spatial attention on current context. This is the quantitative diagnosis of exactly the problem SURF aims to solve — if structural priors improve localization specifically at phase-transition moments (not just steady-state), that becomes the sharpest argument for the prior. Informs ablation design for [[experiments/contrastive alignment]]: ablations should be run at phase boundaries, not averaged over episode.

- [Attention from Action, for Action: Emergent Visual Bottlenecks for Policy Learning](https://www.semanticscholar.org/paper/97c2db623247367a7622c4c8b0c79bb41f098dcc) — arXiv 2026-08-13
  Derives label-free visual ROIs from trajectory data without spatial annotation — gripper events and motion signals define emergent crops that separate where-to-look from how-to-act. Framing identical to Seeker (action-supervised baseline in the open question carried since 09-05) and directly competes with SURF's structural prior at the same architectural level. Key question: when visual structure (line features) and action-derived structure (gripper trajectory) disagree on ROI placement, which predicts policy performance? That disagreement case is where SURF's claim is live.

**adjacent**

- [GuidedAttention: Interpretable and Correctable Visual Attention for OOD-Robust Robot Manipulation via Imitation Learning](https://www.semanticscholar.org/paper/e21e550b5e561747284e9e919d53319b78cb9bf7) — arXiv 2026-07-23
  Predicts task-relevant attention keypoints as an explicit intermediate representation in a diffusion-based visuomotor policy; keypoints are human-correctable at deployment time. Relevant to SURF's interpretability angle: explicit spatial intermediate (keypoints) improves OOD robustness beyond end-to-end attention, which supports the case for an explicit structural prior module rather than implicit attention shaping. The human-correction mechanism is not SURF's path, but the evidence that explicit spatial intermediate → OOD robustness is directly useful.

- [MINERVA: How Small Can a Manipulation Policy Be and Still Solve LIBERO?](https://www.semanticscholar.org/paper/75ee38db94bf920a19799df59cffbda53ca7d54c) — arXiv 2026-09-03
  A 0.54M-parameter visuomotor policy solves LIBERO, establishing the task-specific capacity floor for manipulation benchmarks. Direct calibration for SURF's efficiency argument: if 0.54M parameters suffice for LIBERO, SURF's structural token pruning must justify its training cost by delivering better generalization or harder-task performance, not just matching LIBERO results with fewer FLOPs. Informs experiment selection — results on LIBERO are insufficient to differentiate SURF from trivially compact baselines.

- [Reasoning Without Inference Cost: Latent Semantic Scaffolding for Robot VLA Policies](https://arxiv.org/abs/2609.04893v1) — arXiv 2026-09-04
  Distills explicit reasoning into latent structure during training, eliminating reasoning-token generation at inference; zero inference overhead while retaining the planning benefit of causal chain-of-thought. Relevant to SURF's training-vs-inference cost decomposition: if semantic scaffolding can be baked into weights, a structural prior trained into a VLM's visual attention pattern (rather than computed at inference via a separate prior module) could achieve the same efficiency gain with lower deployment complexity. Alternative architectural path worth tracking.

**horizon**

- [PredVLA: Predictive Sensorimotor Modeling for Sub-Million-Parameter Robot Manipulation](https://www.semanticscholar.org/paper/19feb156fdb49519ab02b042696253ab6b630f0a) — arXiv 2026-08-27

Horizon-level question for compact VLA design.
