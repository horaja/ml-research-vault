# 2026-10-06

## opener

Positioning note is day 42. ThinkProprio lands today as a third token-selection archetype. The current positioning table covers: (1) SURF / GeoScaffold / GSPA — geometric structural prior at input stage; (2) TADP / CogVLA — cross-modal VL attention-based importance; (3) ThinkProprio — proprioception-grounded early gating. ThinkProprio's core finding is that proprioception as a late passive conditioning signal has no effect; value only emerges when proprioception actively gates which visual tokens enter VLM computation. This is the same architectural stance as SURF's structural prior (early, before VLM computation), but the signal is robot state rather than scene geometry. The positioning note must now situate SURF against all three archetypes, not just two — but this sharpens rather than complicates the argument: SURF's prior is task-agnostic, training-free, and scene-geometry-grounded; the other two are either language-anchored or state-anchored.

Wiring Matters provides a directly actionable design constraint: stop-gradient from the VLA backbone to auxiliary supervision is not optional — allowing affordance gradients to reach the backbone dropped LIBERO success 7.6pp. SURF's contrastive prior head faces the same decision. Read before writing the contrastive alignment spec.

Cao et al. is day 7. Still unread. Still required before the positioning note circulates.

**core**

- [Think Proprioceptively: State-Grounded Visual Token Selection for VLA Policies](https://www.semanticscholar.org/paper/2ce0a7201ebc0b4804a7f28d3536338e57e5c345) — Wang et al. · preprint
  Proprioception discretized into VLM-vocabulary tokens gates visual patches before VLM computation; passive late-stage proprioception conditioning has no effect. Third token-selection archetype for the positioning note (state-grounded early gating vs. SURF's geometry-grounded early gating vs. TADP's language-attention gating). Key check: do ThinkProprio-selected and SURF line-drawing-selected patches overlap on the same manipulation frames? If they do, the signals are redundant; if not, proprioception + structural prior is a compound prior worth exploring.

- [Wiring Matters: Injection Topology and Initialization of Affordance Heads in Vision-Language-Action Policies](https://arxiv.org/abs/2610.06318v1) — An et al. · arXiv
  Stop-gradient from VLA backbone to affordance head is load-bearing: removing it drops LIBERO from 93.1% to 85.5%. The correct recipe is: read backbone through stop-gradient, inject intermediate head feature into action expert via a learned bridge. SURF's contrastive prior head is architecturally analogous; this result directly constrains the contrastive alignment spec — stop-gradient is a precondition for the auxiliary geometric head, not an optional choice.

- [History-Conditioned Spatio-Temporal Visual Token Pruning for Efficient Vision-Language Navigation](https://www.semanticscholar.org/paper/4755e2c70d9686aeb663bcb341c339a8edc6df33) — Wang et al. · arXiv
  Training-free VLN token pruning: spatial selection on the current view, spatio-temporal compression on historical memories. Temporal coherence principle: tokens informative at t−1 are likely informative at t, enabling history-conditioned token retention without retraining. VLN not manipulation, but the spatial + temporal decomposition directly maps onto SURF's two-phase framing (structural prior selects spatially; iterative refinement adjusts over time). Supports [[claims/iterative selection]] from the navigation direction.

**adjacent**

- [Gaze on the Prize: Shaping Visual Attention with Return-Guided Contrastive Learning](https://www.semanticscholar.org/paper/ac43acda376c1d2a4c79f236046064b9bb062df8) — Lee et al. · preprint (same lab as @chuangLookFocusAct2025)
  Visual RL agents learn a foveal attention mechanism (Gaze) via a self-supervised contrastive signal derived from return history (Prize): tokens co-occurring with high return are treated as positive pairs. Training-free at test time once the contrastive model is trained. Alternative to SURF's structural prior: instead of geometric signal, uses RL return as the supervision source for learning task-relevant visual attention. Check: does the return-guided gaze land on contact-rich structural regions, or on semantically salient objects (hands, targets) that a geometric prior would miss?

- [Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation](https://www.semanticscholar.org/paper/5f9bb9066630b2bc14ef2d2976c0689bded1f794) — Fu et al. · preprint
  World dynamics modeled in compact VLM token space rather than RGB; avoids the encode-decode loop of RGB world models. Challenge: raw VLM visual tokens are too high-dimensional for efficient autoregressive prediction. SURF's structural token selection is a natural front-end for Token-World: selecting a sparse, geometry-grounded token set before passing to the world model reduces the dimensionality problem while preserving action-relevant information.

- [Video Encoders Built on Image Representations](https://arxiv.org/abs/2610.06616v1) — Zhang et al. · arXiv
  Separates per-frame representation, cross-frame interaction, and token selection into three decoupled operations; compact video encoders built on independent image representations match coupled video encoding at lower token budgets. Baseline framing for SURF's multi-step VLA setting: independent structural selection per frame + optional cross-frame refinement (SURF's iterative step) is a candidate design tested here against fully coupled frame encoding at matched GFLOPs.

**horizon**

- [A single computational objective can produce specialization of streams in visual cortex](https://www.semanticscholar.org/paper/f673f711af4d48c03135e75c4cf08a74fa30e653) — Finzi et al. · bioRxiv
  A self-supervised TDANN (topographic DANN: nearby units respond similarly) produces dorsal/lateral/ventral stream specialization matching fMRI responses better than multi-task DANNs. Stream differentiation emerges from a single topographic objective + task diversity, not from hardwired multi-task structure. Updates [[claims/v4 relevance]]: spatial-structural specialization — the representational basis for SURF's geometric prior — is the kind of organization that emerges naturally from topographic self-supervised training. SURF's prior module approximates a spontaneously efficient representation structure, not an externally imposed biological constraint.
