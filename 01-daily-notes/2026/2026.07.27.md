**ViTacWorld** (arXiv:2607.22530) scales visuo-tactile world models for contact-rich manipulation by generating synthetic tactile interaction data. Tactile feedback patches are the physically-grounded ground truth for contact events — the same events surf's line-density prior claims to identify geometrically. The diagnostic: do surf's line-density heatmaps co-locate with the contact patches ViTacWorld's tactile world model is trained to predict on the same manipulation frames? Positive = structural prior approximates tactile contact geometry; negative = line density captures geometric structure the tactile signal misses, which is equally informative (narrows the claim).

**KEMO** (Zeng et al.) introduces event-driven keyframe selection for long-horizon VLA memory: detect state-transition events, index memory by them. The iterative selection trigger analogue for [[claims/iterative selection]]: if KEMO's event detector identifies when visual state changes enough to warrant a new memory lookup, the same mechanism defines when surf's budget policy should request an additional selection pass. KEMO operationalizes the trigger criterion that [[claims/iterative selection]] currently leaves unspecified.

- ViTacWorld × [[claims/structure helps]]: ViTacWorld predicts contact patches from visual input after training on synthetic visuo-tactile data. - KEMO × [[claims/iterative selection]]: KEMO's event detector decides when a state-transition event has occurred and new memory is warranted. What is the surf analog? When should the iterative selection policy request a new patch allocation pass — when action uncertainty exceeds a threshold, when visual residual exceeds a threshold, or when the event detector signals a scene state change? KEMO's threshold design is a concrete starting point for the stopping criterion.
- Robot-Factored × [[claims/structure helps]]: Robot-Factored decomposes scene changes into robot-body-caused vs. environment-caused residuals. Does surf's line-density prior suppress the robot-rendered foreground patches and select the environment-caused residual patches? If yes, the structural prior implicitly implements robot factorization without explicit rendering — a computationally cheaper version of the same decomposition.
- ResPrune × [[claims/language helps]]: ResPrune identifies tokens not predictable from the language instruction (high residual = task-relevant visual signal beyond language). Is this the same set as surf's contrastive-aligned tokens? Agreement would mean language conditioning already captures what structural prior contributes; disagreement would show structural prior selects visual signal that language-conditioned subspace reconstruction cannot recover.
- Predicting topography × [[claims/v4 relevance]]: If Ribeiro et al. predict V4 functional topography from anatomy, can the same approach predict the shape/texture domain arrangement from @jiangComputationalConstraintsUnderlying? Would unify anatomical and geometric accounts of where to look and make the dispersity prior computationally tractable.
